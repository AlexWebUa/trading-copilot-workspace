# Глоссарий

Алфавитный справочник терминов торговой системы. Каждый термин — краткое определение + ссылка на профильную заметку для углублённого изучения.

**Статусы**:
- 🟢 `defined` — термин определён, ссылка ведёт на заполненную заметку
- 🟡 `partial` — есть базовое определение, но профильная заметка ещё не написана или требует уточнения
- 🔴 `stub` — определение предварительное (догадка/общеиндустриальное), нужно свериться с исходниками автора

**Как использовать**: при анализе исходных файлов возвращаться в этот глоссарий и актуализировать статусы, уточнять определения, добавлять обратные ссылки на профильные заметки в `[[...]]`.

## Латиница / аббревиатуры

### A

- **A-to-B Concept** 🟡 — концепция движения от точки A (инициатива) к точке B (таргет); используется как один из трёх столпов сетапа [[09_Setups/1h3m_by_Bellissimo|1h3m Bellissimo]]. → [[09_Setups/1h3m_by_Bellissimo]]
- **Accumulation** 🟢 — фаза набора позиции крупным капиталом после нисходящего движения. Первая фаза цикла Вайкоффа; внутри боковика проходит структура A → B → C (Spring) → D (LPS, SOS) → E. → [[01_Concepts/Accumulation_Phase]]
- **AH / AL** 🟢 — Asia High / Asia Low. Экстремумы Азиатской сессии как пулы ликвидности. Часто снимаются в начале Лондона. → [[03_Tools/Liquidity_in_Sessions]]
- **AMD** 🟢 — Accumulation · Manipulation · Distribution. Трёхфазовый цикл PO3: накопление ликвидности → манипуляционный выпад → направленная экспансия. Фрактален по всем таймфреймам. Внутри дня: Asia (A) → London (M) → NY (D). → [[05_Sessions_Timings/PO3_AMD]]
- **AMT** 🟢 — Auction Market Theory. Концепция, трактующая рынок как последовательность аукционов с временным равновесием; основа Market Profile. → [[04_Market_Profile/Auction_Market_Theory]]
- **AR** 🟢 — Automatic Rally. Первая реакция после кульминации ([[#SC|SC]]/[[#BC|BC]]): автоматический отскок, формирующий верхнюю границу диапазона накопления (или нижнюю — распределения). → [[01_Concepts/Accumulation_Phase]] · [[01_Concepts/Distribution_Phase]]
- **ASB** 🟢 — Advanced Structure Breakout. Импульсный пробой значимого свингового уровня на старшем ТФ: тело свечи закрывается за границей, часто формируется FVG. Пробитый уровень превращается из границы в базу; точка входа — на ретесте с реакцией. → [[02_Market_Structure/Advanced_Structure_Breakout]]

### B

- **BC** 🟢 — Buying Climax. Кульминация покупок: покупки толпы поглощаются крупными игроками у вершины рынка — сигнал окончания восходящего движения (Phase A распределения). Также используется как маркер локальной верхней границы в Re-accumulation. → [[01_Concepts/Distribution_Phase]] · [[01_Concepts/Accumulation_Phase#Re-accumulation|Re-accumulation]]
- **BE** 🟢 — Break-Even / паттерн «тест точки входа». В контексте **управления позицией**: цена после входа возвращается к POI (точке входа), а затем уходит к таргету. Часто формируется как Re-Sweep («дозаправка»). Правило: всегда ждать теста или ресвипа, не паниковать. → [[11_Trade_Management/Re-Sweep]]
- **BB** (Breaker Block) 🟢 — OB, чья **защищаемая структурная точка (swing high/low) была пробита**: зона инвертирует роль (сопротивление → поддержка и наоборот). На графике пробой почти всегда сопровождается FVG — отсюда визуальный образ «прошитого OB», но определяющий критерий — именно снятие структурного уровня, а не наличие FVG. Работает как POI с повышенной силой, оптимально в связке с FVG C.E. (50 %). → [[03_Tools/Breaker_Block]]
- **BIAS** 🟢 — направленность (ожидаемое направление движения) на конкретном таймфрейме. Определяется через анализ снятой/незакрытой ликвидности и позиции в MS Range (Premium/Discount). → [[06_Bias_Templates/ICT_Daily_Bias]]
- **BISI** 🟢 — Buyside Imbalance / Sellside Inefficiency. При импульсном ап-муве формируется неэффективность на стороне продаж — бычий FVG, магнит для ребалансировки. → [[02_Market_Structure/Price_Delivery_Rebalancing]]
- **BOS** 🟢 — Break of Structure. Пробой значимой структурной точки. **Swing (Context) BOS** — смена контекста; **Fractal/Minor (Entry) BOS** — триггер входа после манипуляции; **cBOS** — подтверждение продолжения тренда. → [[02_Market_Structure/BOS]]
- **BPR** 🟢 — Balanced Price Range. Зона пересечения двух **разнонаправленных** FVG (один бычий + один медвежий); формируется при V-образных движениях, когда встречный импульс оставляет свой FVG поверх первого. Используется как POI и как Entry Model. Не путать с [[#IFVG|IFVG]] (одиночный прошитый FVG без встречного). → [[03_Tools/BPR]]
- **BSL** 🟢 — Buyside Liquidity. Стопы **шортовых** позиций (выше локальных хаев) и отложенные ордера на покупку; топливо для крупного игрока. → [[03_Tools/Liquidity]]
- **BU/LPS** 🟢 — Back Up to Last Point of Support. Откат к зоне поддержки для финального теста перед началом восходящего тренда (Phase D аккумуляции). → [[01_Concepts/Accumulation_Phase]]
- **BU/LPSY** 🟢 — Back Up to Last Point of Supply. Откат к зоне сопротивления после выхода из диапазона распределения — последний тест перед нисходящим трендом. → [[01_Concepts/Distribution_Phase]]

### C

- **CD** 🟢 — Cumulative Delta. Нарастающая сумма дельты (Ask Volume − Bid Volume) за выбранный период. Растущий CD при растущей цене = здоровый тренд; дивергенция (цена обновляет экстремум, CD — нет) = скрытое давление противоположной стороны. Сбрасывается в начале каждой RTH-сессии. → [[04_Market_Profile/Cumulative_Delta]]
- **CVD** 🟢 — Cumulative Volume Delta. Синоним [[#CD|CD]] в ряде платформ (Exocharts, Sierra Chart). → [[04_Market_Profile/Cumulative_Delta]]
- **cBOS** 🟢 — Continuation / Confirmed BOS. Подтверждение **продолжения** текущей структуры: цена обновляет экстремумы в направлении тренда без его смены. → [[02_Market_Structure/BOS]]
- **CBDR** 🟢 — Central Bank Dealers Range. Диапазон **2 PM – 8 PM NY** (23:00–03:00 Kiev); со стандартными отклонениями (ST DIV 1/2/3/4) определяет High/Low дня в D1 PO3. Идеальный Range ≤ 40 pips (опт. 20–30), типично до 3 отклонений, ≤ 2 — идеал. Рабочий ТФ — 15M; тянется по телам свечей. → [[03_Tools/CBDR]]
- **C.E.** 🟢 — Consequent Encroachment. 50% зоны FVG (середина неэффективности); ключевой внутренний уровень реакции в ребалансировке. → [[02_Market_Structure/Price_Delivery_Rebalancing]]
- **CHoCH** 🟢 — Change of Character. В широком трейдинговом сообществе (SMC/ICT): **первый** пробой структуры **против** действующего тренда — сигнал потенциальной смены направления. Отличается от BOS тем, что BOS продолжает тренд (обновление хая в бычьей структуре), тогда как CHoCH ломает его (пробой последнего HL в бычьей структуре вниз). В данной системе вместо CHoCH используется термин **[[#MSS|MSS]]** (Market Structure Shift) — понятия идентичны по сути. Различие лишь терминологическое: авторы системы работают с MSS и Displacement как с триггером, тогда как в SMC-сообществе тот же момент называется CHoCH. → [[02_Market_Structure/Market_Structure_Shift]]
- **Compression** 🟢 — LRLR (Low Resistance Liquidity Run): сжатый ценовой диапазон с «билдингом ликвидности» по одну сторону; после снятия локальных целей становится причиной **агрессивного обратного движения** через всю компрессию. Классический ТА воспринимает как уровень — Smart Money как скопление ликвидности. Используется как цель для сделки. → [[03_Tools/Compression]]

### D

- **Delta** 🟢 — разница между объёмом агрессивных покупок (Ask Volume) и продаж (Bid Volume) за свечу или период: Delta = Ask − Bid. Положительная дельта → доминирование покупателей; отрицательная → продавцов. Базовый элемент Footprint-анализа и Cumulative Delta. → [[04_Market_Profile/Footprint_Imbalances]] · [[04_Market_Profile/Cumulative_Delta]]
- **DO** 🟢 — Daily Open. Цена на начало новых суток (00:00 UTC или локальное время). Используется как ориентир манипуляции в Daily PO3: бычий день → провал ниже DO (London Judas), медвежий день → выпад выше DO. → [[05_Sessions_Timings/PO3_AMD]]
- **Displacement** 🟢 — импульсное агрессивное движение в момент структурного сдвига, оставляющее FVG. Свечи с большими телами, короткими тенями и разрывами между ними. Обязательный атрибут валидного MSS. → [[02_Market_Structure/Market_Structure_Shift]]
- **Distribution** 🟢 — фаза фиксации прибыли: крупный капитал сбрасывает актив розничным участникам на максимумах. Зеркальное отражение аккумуляции; структура A → B → C (UTAD) → D (LPSY, SOW) → E. → [[01_Concepts/Distribution_Phase]]
- **DP** 🟢 — Decision Point. Ключевая точка графика (обычно FVG), от которой ждём реакции: уважение → продолжение контекста; инверсия → зона становится POI для противоположного направления. HTF: 4H/1D (глобальный план); интрадей: 30M/1H (сессионные DP). → [[07_POI/Decision_Point_DP]]
- **DWMY** 🟢 — Daily / Weekly / Monthly / Yearly Opens. Ценовые уровни открытия соответствующих периодов. Четыре паттерна взаимодействия: Аккумуляция под, Дистрибуция над, Тест (ложный пробой), Флип (смена тренда). Анализируются сверху вниз в связке с HTF bias. → [[06_Bias_Templates/DWMY_Opens]]

### E

- **ETH** 🟢 — Extended Trading Hours. Расширенная торговая сессия вне RTH (овернайт, пре/постмаркет). Для индексных фьючерсов — меньше объёма, больше шума; зоны ценности из ETH условны. → [[04_Market_Profile/RTH_vs_ETH]]

### F

- **Failure Swing** 🟢 — попытка обновить предыдущий экстремум, которая не удаётся; часто предшествует MSS (резкому импульсу в противоположную сторону). → [[02_Market_Structure/Market_Structure_Shift]]
- **Footprint** 🟢 — кластерный (Footprint) график: для каждого ценового уровня внутри свечи отображается объём на Bid и Ask раздельно. Позволяет видеть кто был агрессором — покупатели (Market Buy = Ask Volume) или продавцы (Market Sell = Bid Volume). Ключевые паттерны: [[#Imbalance (Orderflow)|Orderflow Imbalance]], [[#Stacked Imbalances|Stacked Imbalances]], Absorption, Exhaustion. Требует L2/тиковых данных; рекомендуются платформы Exocharts, Sierra Chart, Bookmap. → [[04_Market_Profile/Footprint_Imbalances]]
- **FTA** 🟢 — First Trouble Area. Первая точка (POI, ликвидность, уровень), от которой цена может дать реакцию и потенциально сменить тренд — ближайшее препятствие на пути к таргету. При достижении FTA нужно убедиться, что это реакция на уровень с продолжением HTF-движения, а не разворот контекста. → [[07_POI/Context_BIAS_POI]]
- **FullFill** 🟢 — 100%-ное перекрытие FVG; синоним полной ребалансировки (re-balance). → [[02_Market_Structure/Price_Delivery_Rebalancing]]
- **FVG** 🟢 — Fair Value Gap. Трёхсвечная формация имбаланса (тень средней свечи не перекрыта соседними). Глубина теста: [[#IOFED|IOFED]] (≥ 1 %) → [[#C.E.|C.E.]] (50 %) → [[#FullFill|FullFill]] (100 %). Применяется как POI на HTF и как модель входа на LTF; синхронизируется по ТФ-парам (4H+1H, 4H+30M, 1H+15M, 15M+5M). → [[03_Tools/FVG]]
- **Fractal** 🟢 — Фрактальная точка: самый высокий/низкий high/low среди 3 свечей. Используется для определения высоколиквидных точек на старшем ТФ и как основа Minor BOS. → [[02_Market_Structure/Fractals]]

### G

- **GAP** 🟢 — Ценовой разрыв между двумя свечами (открытие после выходных / крупного перерыва). Разметка — инструментом Фибоначчи от экстремума первой свечи до начала следующей. Используется как POI на HTF и точечно как модель входа на LTF. → [[03_Tools/GAP]]
- **Golden Rain** 🔴 — Stub: исходная заметка содержит только структуру (Intro/Base/Context/Entry models/TP/RM) без наполнения; backtest Jan–Jun 2022 недоступен. → [[03_Tools/Golden_Rain]] · [[_Ambiguities]]

### H

- **HVN** 🟢 — High Volume Node. Уровень/зона в Volume Profile с аномально высоким объёмом — признак принятия цены (acceptance). Цена замедляется и ротирует вблизи HVN; выступает поддержкой/сопротивлением. TPO-аналог: зона с широким профилем и большим количеством TPO-блоков. → [[04_Market_Profile/Volume_Profile]]

### I

- **IB** 🟢 — Initial Balance. Диапазон (High/Low) первых 60 минут RTH-сессии — первое столкновение покупателей и продавцов. Ширина IB определяет вероятный тип дня: узкий → расширение, широкий → консолидация. Границы IB (IBH/IBL) — ключевые внутридневные уровни. Неприменим для крипты. → [[06_Bias_Templates/Initial_Balance]]
- **IDAR** 🔴 — (требует уточнения из источника — предположительно «Initial Day Auction Range»). → [[04_Market_Profile/OAR_IDAR]]
- **IDM / Inducement** 🟢 — вид ликвидности вблизи границ POI, используемый как «приманка»: заставляет цену протестировать POI глубже и одновременно служит топливом для разворотного движения. 4 вариации: FVG<50%, минимальный тест POI, дистрибьюция/аккумуляция перед POI, STH/STL как приманка для ITH/ITL. Правило: всегда ждать снятия индюсмента перед POI. → [[03_Tools/Inducement]]
- **IFVG** 🟢 — Inversion FVG. **Прошитый FVG без образования встречного FVG** (одна «ступень»). После пробоя меняет функцию: бычий → сопротивление, медвежий → поддержка. Не путать с [[#BPR|BPR]] (пересечение двух FVG). → [[03_Tools/IFVG]]
- **IMB** (Imbalance) 🔴 — имбаланс, неэффективность доставки цены. Синонимично FVG в ряде контекстов, может использоваться как модель входа. → [[03_Tools/Imbalance]]
- **IOF** 🟢 — Institutional Order Flow. Подвид OF, появляющийся на LTF при тесте HTF POI или снятии крупных пулов ликвидности. Элементы: MS Shift, Flip, OF Break, Rebalance, LG, Advanced MS. Формируется в 3 части; даёт несколько точек входа в рамках одного движения. → [[07_POI/IOF]]
- **IOFED** 🟢 — Institutional Order Flow Entry Drill. Тест FVG **от ближайшего края до C.E.** (≈50 %). Агрессивная модель входа ICT; применяется, **если выше/ниже уже отработан FullFill** соседнего FVG и цена может не пройти до 100 %. → [[03_Tools/IOFED]]
- **ITH / ITL** 🟢 — Intermediate-Term High / Low. Среднесрочные свинги (H1–M15), обозначающие локальные зоны удержания/разворота внутри LT-контекста. Два типа: Type 1 — между двумя STH после импульса; Type 2 — на ребалансировке FVG. → [[02_Market_Structure/Advanced_Market_Structure]]

### J

- **Judas Swing** 🟢 — ложное свинговое движение в начале London/pre-NY (00:00–05:00 EST), направленное противоположно BIAS дня. Условие: Asia — боковик, манипуляция над AH/AL перед свингом. Формирует экстремум дня. Инструмент понимания, не вход. → [[08_Entry_Models/ICT_Judas_Swing]]

### K

- **Key High / Key Low** 🟢 — ключевой максимум/минимум, пробитие которого подтверждает (cBOS) или ломает (BOS) структуру. Границы MS Range; опорные уровни для поиска POI. → [[02_Market_Structure/Market_Structure]] · [[02_Market_Structure/Market_Structure_Range]]

### L

- **LH / LL** (Session) 🟢 — London High / London Low. Экстремумы Лондонской сессии как пулы ликвидности внутри дня. → [[03_Tools/Liquidity_in_Sessions]]
- **Liquidity** 🟢 — Области концентрации **стоп-ордеров** ритейла. Крупный игрок **формирует уровни**, чтобы толпа оставила стопы, затем **приходит за ликвидностью** — набирает/распределяет позицию. Делится на **BSL** (над хаями) и **SSL** (под лоями). После снятия пула ожидается реакция (в идеале — MSS). → [[03_Tools/Liquidity]]
- **LPS** 🟢 — Last Point of Support. Последняя точка поддержки внутри диапазона аккумуляции (Phase D); точка, после которой начинается движение вверх. LPS может быть несколько. → [[01_Concepts/Accumulation_Phase]]
- **LPSY** 🟢 — Last Point of Supply. Последняя точка предложения в диапазоне распределения (Phase D); может быть несколько; предшествует нисходящему импульсу. → [[01_Concepts/Distribution_Phase]]
- **LTH / LTL** 🟢 — Long-Term High / Low. Долгосрочные свинги (D, W, M), задающие контекст рынка (bias) и основные зоны ликвидности. Опорный уровень для Advanced Market Structure. → [[02_Market_Structure/Advanced_Market_Structure]]
- **LVN** 🟢 — Low Volume Node. Уровень/зона в Volume Profile с аномально низким объёмом — признак отторжения цены (rejection). Рынок прошёл этот уровень быстро, не оставив сделок. Цена движется через LVN без сопротивления — «дыра» в профиле, ускоряющая движение. TPO-аналог: [[#Single Prints|Single Prints]]. → [[04_Market_Profile/Volume_Profile]]

### M

- **Macros (ICT)** 🟢 — 7 временны́х окон повышенной алгоритмической активности: London (2), NY AM (2), Lunch (1), PM (2). Три типа: Accumulation (не торговать), Manipulation (снятие SSL/BSL → вход), Distribution (удерживать/входить). Тайминги EST и Kyiv (UTC+2/UTC+3). → [[05_Sessions_Timings/ICT_Macros]]
- **MB** (Mitigation Block) 🟢 — Импульсно пробитый low/high, который **не снимает ликвидность** старого экстремума. Возврат к нему = место, где участники «в ловушке» закрывают убытки. Работает как OB/Breaker. Рекомендуется комбинировать с [[#SMT|SMT]]. Расширенная **Mitigation-логика** (3 сценария: Zone-to-Zone, Zone-to-Liquidity-Sweep, Zone-to-SMT) показывает, когда противоположная зона перестаёт быть FTA. → [[03_Tools/Mitigation_Block]]
- **MMBM** 🟢 — Market Maker Buy/Sell Model. Шаблонная 6-шаговая модель поведения маркет-мейкера. Buy: Consolidation → Run to Support → Smart Money Reversal → Accumulation → Re-accumulation → Distribution. Sell Model — зеркально. SMT-дивергенция в шаге 3 = ключевое подтверждение. → [[06_Bias_Templates/Market_Maker_Model]]
- **Momentum** 🟢 — скорость и продолжительность коррекции относительно основного движения. В системе используется для оценки качества подхода к POI: долгая вялая коррекция (с пулами ликвидности) → высокая вероятность реакции от POI; OF против POI → пропустить позицию. → [[11_Trade_Management/Momentum]]
- **MS Range** 🟢 — Market Structure Range. Диапазон между Key High и Key Low текущей структуры. Позволяет оценить, истинное ли движение наблюдается. → [[02_Market_Structure/Market_Structure_Range]]
- **MSS** 🟢 — Market Structure Shift. Смена фазы движения: пробой ключевого swing high/low **против** предыдущего тренда, обычно с Displacement и FVG. Может фиксироваться даже без пробоя старшего свинга (по пробою внутреннего экстремума с сильным импульсом). → [[02_Market_Structure/Market_Structure_Shift]]

### N

- **NDOG** 🟢 — New Day Opening Gap. Разрыв между закрытием в 4:59 PM и открытием в 6:00 PM для торговых дней. Краткосрочно — магнит (цель перекрытия); долгосрочно — поддержка/сопротивление. Отмечать только крупные гэпы, только внутри текущей недели. → [[05_Sessions_Timings/NDOG_NWOG]]
- **NWOG** 🟢 — New Week Opening Gap. Разрыв между закрытием в пятницу 4:59 PM и открытием в воскресенье 6:00 PM. Аналогичная NDOG логика; отмечать 4–5 последних гэпов. → [[05_Sessions_Timings/NDOG_NWOG]]
- **NYM** 🟢 — New York Midnight. Цена открытия дня в 00:00 EST (07:00 Kyiv). Предпочтительный ориентир Daily PO3 для USD-пар и американских индексов. Уровень манипуляции: бычий день → провал ниже NYM в Лондоне → лонг. → [[05_Sessions_Timings/PO3_AMD]]

### O

- **OAR** 🟢 — Opening Auction Range. Диапазон (High/Low) утреннего аукциона Xetra (08:50–09:00 CET). Институциональный баланс перед открытием непрерывной торговли. 2 сетапа: Range Breakout & Retest и Inversion & Retest. Используется в связке с VWAP и IDAR. → [[04_Market_Profile/OAR_IDAR]]
- **OB** (Order Block) 🟢 — Последняя **противоположная свеча** перед импульсом: bullish OB = последняя красная перед ростом, bearish OB = последняя зелёная перед падением. Правила: контекст структуры, наличие IMB после OB, отсутствие встречной ликвидности за зоной. В системе предпочтение отдаётся [[#SC|SC]] (OB, снявшему ликвидность). → [[03_Tools/Order_Block]]
- **OF** 🟢 — Order Flow. Структурное движение цены, в процессе которого снимается вся ликвидность на пути. Формируется после 2 подтверждений (манипуляция/IMB + обновление экстремума). Инвалидируется при 2 подтверждениях у первого таргета (зарождение нового OF) или при «обнулении информации». → [[11_Trade_Management/Order_Flow]]
- **OTE** 🟢 — Optimal Trade Entry. Детализированная зона внутри Premium/Discount: уровни Фибоначчи **0.620 / 0.705 / 0.790**. Применяется только в связке с контекстом и другими факторами входа. → [[03_Tools/Fibonacci_Premium_Discount_OTE]]
- **OTT** 🟢 — Optimal Time Trade. Временное окно, когда разрешён набор позиции. По Bellissimo: 09:00–17:00 Киев. → [[09_Setups/1h3m_by_Bellissimo]]

### P

- **PD** 🟢 — Previous Day. Уровни предыдущего дня (OAR, IDAR, SP) действуют как зоны поддержки/сопротивления и памяти рынка на следующий день. → [[04_Market_Profile/OAR_IDAR]]
- **PDH / PDL** 🟢 — Previous Day High / Low. Экстремумы предыдущего дня как **ключевые пулы ликвидности** и одновременно цели для TP. При открытии нового дня цена охотится за PDH/PDL. → [[03_Tools/Liquidity_in_Sessions]]
- **PO3** 🟢 — Power of Three. Трёхфазовый цикл: Accumulation → Manipulation → Distribution. Фрактален на всех ТФ (свеча, час, день, неделя, месяц). Daily PO3: DO/NYM как ориентир манипуляции; Weekly PO3: ≈70% экстремумов недели в первые 3 дня. → [[05_Sessions_Timings/PO3_AMD]]
- **POC** 🟢 — Point of Control. Уровень с наибольшим объёмом/временем внутри профиля. Двойственная природа: **магнит** (цена тяготеет к нему в балансе) или **барьер** (агрессивное отторжение = слом баланса). Центр Value Area. → [[04_Market_Profile/POC]]
- **POI** 🟢 — Point of Interest. Зона интереса (OB, FVG, IMB, BPR, Breaker и т. п.) от которой рассматривается вход. 5 правил: Premium/Discount, сняла ликвидность, нет ликвидности за зоной, нетестирована, синхронизация со структурой. POI = «заправка» для продолжения тренда, не для разворота. → [[07_POI/POI]]
- **Poor High / Poor Low** 🟢 — Экстремум без «хвоста» и без агрессивной кульминации, с двумя и более TPO подряд. Маркер **незавершённого аукциона**: рынок вернётся для финального теста. Не сигнал на вход, а **потенциальная цель**. → [[04_Market_Profile/Poor_High_Low]]
- **Premium / Discount** 🟢 — Зоны по Fibonacci (0 · 0.5 · 1): выше 0.5 — Premium (для шортов), ниже 0.5 — Discount (для лонгов), 0.5 — Equilibrium. Smart Money покупает в Discount, продаёт в Premium. → [[03_Tools/Fibonacci_Premium_Discount_OTE]]
- **PS** 🟢 — Preliminary Support. Предварительная поддержка: первые покупатели после длительного падения, силы которых ещё недостаточно, чтобы остановить нисходящее движение (Phase A аккумуляции). → [[01_Concepts/Accumulation_Phase]]
- **PSY** 🟢 — Preliminary Supply. Предварительное предложение: первые крупные продажи после длительного роста — признаки торможения восходящего движения (Phase A распределения). Также используется как маркер начала локального Re-accumulation / Re-distribution. → [[01_Concepts/Distribution_Phase]] · [[01_Concepts/Accumulation_Phase#Re-accumulation|Re-accumulation]]
- **PWH / PWL** 🟢 — Previous Week High / Low. Экстремумы предыдущей недели как пулы ликвидности. При открытии новой недели цена охотится за PWH/PWL. → [[03_Tools/Liquidity_in_Sessions]]

### R

- **RB** (Rejection Block) 🟢 — Модель из **2 свечей**: первая проходит в направлении импульса, вторая открывается выше/ниже её экстремума, оставляя **длинную тень-отбой**. Блок = тело свечи + 50 % тени до экстремума. Используется с подтверждением ([[#SMT|SMT]], [[#MSS|MSS]]). → [[03_Tools/Rejection_Block]]
- **Re-accumulation** 🟢 — повторная аккумуляция внутри уже начавшегося восходящего тренда: «отдых» движения, во время которого крупный капитал добирает позицию. Причина слабее исходной Accumulation → следствие слабее. → [[01_Concepts/Accumulation_Phase#Re-accumulation|Re-accumulation]]
- **Re-distribution** 🟢 — повторное распределение внутри нисходящего тренда; добор шорт-позиции крупным капиталом. → [[01_Concepts/Distribution_Phase#Re-distribution|Re-distribution]]
- **Re-Sweep** 🟢 — повторное тестирование уровня или POI после первоначального снятия ликвидности («дозаправка»). 3 причины: (1) OF на пути к высоколиквидному пулу — ждать инвалидации OF; (2) межсессионный тайминг; (3) новостной триггер. Паттерн BE → TP: цена возвращается к точке входа, затем уходит к таргету. → [[11_Trade_Management/Re-Sweep]]
- **RTGS** 🟢 — Real-Time Gross Settlement / Target2. Европейская межбанковская система расчётов в реальном времени (ЕЦБ). В торговой системе: период 08:00–09:00 Киев = снижение ликвидности (APAC/EMEA закрывают позиции). Используется в связке с **Search Hunt**. → [[11_Trade_Management/Theory_of_RTGS]]
- **RTH** 🟢 — Regular Trading Hours. Основная торговая сессия инструмента. Для USA индексов: 16:30–23:00 Kyiv; для EURO: 10:00–18:30 Kyiv. Профиль строится по RTH-данным (через STPO). Для крипты понятие RTH отсутствует. → [[04_Market_Profile/RTH_vs_ETH]]

### S

- **Search Hunt (SH)** 🟢 — период 08:00–09:00 Киев, в котором цена работает с ликвидностью Азии (AH/AL). По характеру движения в SH прогнозируется направление на Франкфурт. Связан с закрытием позиций APAC в рамках системы RTGS. → [[11_Trade_Management/Theory_of_RTGS]]
- **SC** (Selling Climax) 🟢 — Кульминация продаж: панические продажи толпы поглощаются крупным игроком, нисходящее движение останавливается (Phase A аккумуляции). → [[01_Concepts/Accumulation_Phase]]
- **SC** (Sponsored Candle) 🟢 — Спонсированная свеча: OB, **снявший ликвидность**. Разметка идентична OB, но дополнительно требуется факт снятия пула. В системе классический OB не используется — приоритет отдаётся SC. → [[03_Tools/Sponsored_Candle]]
- **Silver Bullet** 🟢 — ICT-сетап на чётких таймингах (03:00–04:00, 10:00–11:00, 14:00–15:00 EST): снятие пула ликвидности (BSL/SSL) + Swing BOS через закрепление. Без Bias/контекста, только 1M (иногда 15M). RR ≥ 1/1.3, риск 1%. TP — ближайшие BSL/SSL. → [[08_Entry_Models/ICT_Silver_Bullet]]
- **Single Prints** 🟢 — одиночные TPO внутри профиля (не на краю): результат одностороннего импульса, цена прошла уровень без накопления. Индикатор силы движения (длиннее блок = мощнее дисбаланс) и маркер VA Breakout / Initiative движения. Впоследствии заполняются или становятся структурными границами. → [[04_Market_Profile/Single_Prints]]
- **SLQ** (Structural Liquidity) 🟢 — Ликвидность на ключевых точках **внутри структуры**. Движения делятся на **healthy** (SLQ активно снимается) и **unhealthy** (оставляется за собой → вернётся за сбором). Основной источник топлива для RTO. → [[03_Tools/Structural_Liquidity]]
- **SMT** 🟢 — Smart Money Technique / Divergence. **Рассинхрон** между коррелирующими активами (прямая или обратная корреляция). Указывает на разворотную ситуацию: работать нужно **от сильного актива** (снявшего ликвидность). Сам по себе бесполезен — только как **дополнительное подтверждение**. → [[03_Tools/SMT_Divergence]]
- **SOS** 🟢 — Sign of Strength. Признак силы: импульсное движение вверх на больших объёмах, подтверждающее доминирование покупателей после аккумуляции (Phase D). → [[01_Concepts/Accumulation_Phase]]
- **SOW** 🟢 — Sign of Weakness. Признак слабости: агрессивное нисходящее движение после распределения (Phase B/D); может появляться как выше, так и ниже уровня AR в Phase B. → [[01_Concepts/Distribution_Phase]]
- **SP** 🟢 — Settlement Price. Цена расчётного закрытия Xetra (17:30 CET, VWAP последних 5 минут торгов). Действует как уровень памяти рынка на следующий день: ценовая метка, к которой рынок возвращается для ребалансировки. → [[04_Market_Profile/OAR_IDAR]]
- **SSMT** 🟢 — Sequential Smart Money Technique. SMT, образующееся между **последовательными кварталами** + между двумя/тремя коррелирующими активами. Экстремумы не обязаны формироваться одновременно — главное, чтобы это были экстремумы своего квартала. Инвалидируется SSMT старшего цикла. Требует подтверждения на LTF + наличия FVG для входа. → [[06_Bias_Templates/Quarterly_Theory]]
- **Spring** 🟢 — последняя манипуляция в аккумуляции (Phase C): ложный пробой нижней границы диапазона для сбора ликвидности слабых продавцов. В ряде схем отсутствует. → [[01_Concepts/Accumulation_Phase]]
- **SSL** 🟢 — Sellside Liquidity. Стопы **лонговых** позиций (под локальными лоями) и отложенные ордера на продажу; топливо для крупного игрока. → [[03_Tools/Liquidity]]
- **Sponsored candle** 🟢 — см. [[#SC (Sponsored Candle)|SC (Sponsored Candle)]]. → [[03_Tools/Sponsored_Candle]]
- **ST** 🟢 — Secondary Test. Вторичный тест кульминационного уровня (SC/BC); может быть несколько. Проверяет действительность окончания предшествующего движения. → [[01_Concepts/Accumulation_Phase]] · [[01_Concepts/Distribution_Phase]]
- **STBBTS** 🟢 — STB/BTS (Sell to Buy / Buy to Sell). Зона спроса/предложения от BOS/cBOS до ближайшего экстремума. Правила: снимает ликвидность, импульсные движения, IMB внутри. HTF: POI для контекста; LTF: вход по факторам внутри зоны. → [[09_Setups/STB_BTS]]
- **STDV** 🟢 — Standard Deviation Projection. Кратные проекции базового ценового диапазона (импульса) вперёд с помощью Fibo (уровни –1, –2, –2.5, –4). STDV–1 = первое препятствие, –2/–2.5 = критическая зона (признак перегрева), –4 = предельное расширение (финальный таргет). Используется вместе с контекстом и ликвидностью. → [[04_Market_Profile/Standard_Deviation_STDV]]
- **STH / STL** 🟢 — Short-Term High / Low. Краткосрочные свинги (M5–M1) для точного тайминга входа. Решения привязываются к ITH/ITL; если STH/STL идёт против рабочей структуры — ожидаем восстановления. → [[02_Market_Structure/Advanced_Market_Structure]]
- **STPO** 🟢 — Session Time Price Opportunity. Индикатор TradingView: Market Profile с настраиваемыми временными границами сессии. Позволяет изолировать RTH от ETH. Обязателен для работы с индексными фьючерсами (USA: 16:30–23:00, EURO: 10:00–18:30 Kyiv). Для крипты не нужен. → [[04_Market_Profile/TPO_STPO]]
- **Strong High / Strong Low** 🟢 — сильный экстремум: приводит к агрессивному слому или подтверждению структуры. Зона для набора позиции. → [[02_Market_Structure/Strong_Weak_Structural_Points]]
- **SIBI** 🟢 — Sellside Imbalance / Buyside Inefficiency. При импульсном шорт-движении формируется неэффективность на стороне покупок — медвежий FVG. → [[02_Market_Structure/Price_Delivery_Rebalancing]]

### T

- **Tail** 🟢 — «хвост» профиля (Buying/Selling Tail): серия одиночных TPO на краю профиля (≥2–3 блока), где рынок мгновенно отверг цену. Buying Tail — снизу (продавцы поглощены покупателями), Selling Tail — сверху (покупатели исчерпаны). Сильная зона поддержки/сопротивления. Не путать с [[#Single Prints|Single Prints]] (внутри профиля). → [[04_Market_Profile/Buying_Selling_Tail]]
- **TGIF** 🟢 — Thank God It's Friday. Паттерн формирования финального экстремума недельной свечи в пятницу: манипуляция образует максимум (бычья неделя) или минимум (медвежья), после чего движение идёт к закрытию недели. 3 условия: ПН–ВТ формирует противоположный экстремум, ЧТ–ПТ — финальный, цена достигает HTF-цели. Применение: контрнедельное движение в пятницу. → [[09_Setups/TGIF_Setup]]
- **True Open** 🟢 — начало Q2 каждого квартального цикла. Временной фильтр для определения Judas Swing / Stop-Hunt. Бычий контекст → покупаем ниже True Open; медвежий → продаём выше. Тайминги: год (1-й пн апреля), месяц (2-й пн), неделя (пн 18:00 NY), день (00:00), сессии (Азия 19:30, Лондон 01:30, NY 07:30, PM 13:30). → [[06_Bias_Templates/Quarterly_Theory]]
- **TPO** 🟢 — Time Price Opportunity. Единица времени (30-минутный блок, обозначается буквой), проведённого ценой на уровне — базовый элемент Market Profile. Количество TPO на уровне = активность рынка. В TradingView реализован как индикатор TPO (дневной) и STPO (сессионный). → [[04_Market_Profile/TPO_STPO]]

### Q

- **QM** (Quasimodo) 🟡 — паттерн разворота ICT/SMC: ложное обновление экстремума с последующим импульсным движением в противоположную сторону. Когда QM не формируется — альтернативой служит [[#MSS|MSS]]. → _(заметка пока не создана)_

### U

- **UT** 🟢 — Upthrust. Первая манипуляция у верхней границы сопротивления в Phase B распределения — выход за диапазон для сбора ликвидности перед UTAD. → [[01_Concepts/Distribution_Phase]]
- **UTAD** 🟢 — Upthrust After Distribution. Последняя манипуляция в распределении (Phase C): ложный пробой верхней границы, заманивающий слабых покупателей — аналог Spring, но вверх. В ряде схем отсутствует. → [[01_Concepts/Distribution_Phase]]

### V

- **VA** 🟢 — Value Area. Область ценового консенсуса: ≈68–70% всех TPO/объёма. Внутри VA — баланс и ротация. Выход за VA = потенциальный дисбаланс. Сценарии: VA Breakout (инициатива), Move inside VA (Responsive), Move outside VA (принятие или Failed Auction). → [[04_Market_Profile/Value_Area]]
- **VAH / VAL** 🟢 — Value Area High / Low. Верхняя/нижняя граница VA. Ключевые уровни для сценариев Initiative и Responsive: VAH — зона Responsive Selling / Initiative Buying, VAL — зона Responsive Buying / Initiative Selling. → [[04_Market_Profile/Value_Area]]
- **VP** 🟢 — Volume Profile. Горизонтальная гистограмма распределения объёма по ценовым уровням за выбранный период. Типы: Session VP, Fixed Range VP, Visible Range VP, Composite VP. Ключевые элементы: POC (максимальный объём), Value Area (70% объёма), HVN (зона принятия), LVN (зона отторжения). В отличие от TPO-профиля измеряет не время, а реальный денежный поток. → [[04_Market_Profile/Volume_Profile]]
- **VWAP** 🟢 — Volume Weighted Average Price. Средневзвешенная по объёму цена — институциональный бенчмарк исполнения. Типы: Session / Weekly / Monthly / Anchored. Элементы: Mean (±0σ), ±1σ (68% активности), ±2σ (95%). Воспринимать как зону, не линию. Применяется: динамический уровень, TP (mean-reversion к Midpoint), фильтрация сделок у OAR/IDAR. → [[04_Market_Profile/VWAP]]

### W

- **WO** 🟢 — Weekly Open. Цена открытия недели. Ориентир для Weekly PO3: бычья неделя → провал ниже WO (манипуляция) → возврат выше WO (экспансия); медвежья → выпад выше WO → возврат под WO. → [[05_Sessions_Timings/PO3_AMD]]
- **Wyckoff** 🟢 — метод Р. Вайкоффа: анализ действий крупного капитала через фазы Accumulation / Re-accumulation / Distribution / Re-distribution и диапазоны A–E. Базируется на двух законах: спроса/предложения и причины/следствия. → [[01_Concepts/Wyckoff_Method]]

## Концепции (русский)

- **Баланс / Дисбаланс** 🟢 — состояние рынка: баланс = ротация внутри диапазона, профиль симметричен, консенсус достигнут; дисбаланс = направленный ход, асимметричный профиль, Single Prints, смещение VA. Рынок находится в балансе ≈70–80% времени. → [[04_Market_Profile/Market_Rotation_in_Balance]] · [[04_Market_Profile/Profile_Logic]]
- **Внутренняя / Внешняя структура** 🟢 — иерархия структурных точек: Swing/Context-структура и Minor-структура **на одном ТФ**; межтаймфреймовая иерархия LT → IT → ST. → [[02_Market_Structure/Market_Structure]] · [[02_Market_Structure/Advanced_Market_Structure]]
- **Восходящая / Нисходящая структура** 🟢 — тип структуры: повышение HH/HL (бычья, приоритет лонг) vs понижение LH/LL (медвежья, приоритет шорт). → [[02_Market_Structure/Market_Structure]]
- **Дистрибьюция / Ре-дистрибьюция** 🟢 — фазы распределения актива (см. [[01_Concepts/Distribution_Phase]]).
- **Доставка цены (эффективная / неэффективная)** 🟢 — Price Efficient (без FVG) vs Price Inefficient (с FVG, магнитом для ребалансировки). → [[02_Market_Structure/Price_Delivery_Rebalancing]]
- **Имбаланс (неэффективная доставка цены)** 🟢 — см. [[#FVG|FVG]] / [[#BISI|BISI]] / [[#SIBI|SIBI]]. → [[02_Market_Structure/Price_Delivery_Rebalancing]]
- **Минорная структура** 🟢 — мелкие max/min внутри свинг-структуры **на том же ТФ**; используется для тайминга входа через Minor BOS. → [[02_Market_Structure/Market_Structure]] · [[02_Market_Structure/BOS]]
- **Накопление / Ре-накопление** 🟢 — фазы набора позиции (см. [[01_Concepts/Accumulation_Phase]]).
- **Поглощение / Митигация** 🔴 — закрытие противоположных позиций в ключевой зоне. → [[03_Tools/Mitigation_Block]]
- **Ребалансировка** 🟢 — возврат цены в неэффективные зоны для закрытия имбаланса. Глубина: IOFED (≥1%) → C.E. (50%) → FullFill (100%). → [[02_Market_Structure/Price_Delivery_Rebalancing]]
- **Свинг** 🟢 — направленное колебание между двумя структурными точками; может быть классифицирован как сильный или слабый. → [[02_Market_Structure/Strong_Weak_Structural_Points]]
- **Сессия** 🟢 — временной блок торговой активности: Asia (01–05 Kyiv), Frankfurt (10–11), London (10–14), Lunch (14–16:30), NY AM/RTH (16:30–23:00). Взаимосвязаны: характер предыдущей сессии определяет ожидания для следующей. → [[05_Sessions_Timings/Session_Dynamics]]
- **Сильные / Слабые структурные точки** 🟢 — классификация HH/HL/LH/LL по качеству формирования: сильные — зона набора позиции, слабые — цель для фиксации/снятия ликвидности. → [[02_Market_Structure/Strong_Weak_Structural_Points]]
- **Снятие ликвидности (Sweep)** 🔴 — касание/пробитие уровня для сбора стоп-ордеров. → [[03_Tools/Liquidity]]
- **Open Type** 🟢 — тип открытия RTH-сессии. Четыре вида: Open Drive (максимальная инициатива), Open Test Drive (тест → подтверждение), Open Rejection Reverse (попытка → разворот), Open Auction (двусторонний, без направления). Определяет начальный контекст и вероятный тип дня. → [[06_Bias_Templates/Open_Types]]
- **Ротация** 🟢 — фаза движения цены в балансе: горизонтальные колебания между VAH и VAL без направленной инициативы. Доминирует ≈70–80% торгового времени. Эффективная тактика: контртрендовая торговля от краёв VA к POC. → [[04_Market_Profile/Market_Rotation_in_Balance]]
- **Initiative / Responsive** 🟢 — два типа рыночной активности на границах VA. Initiative: цена выходит за VA и не возвращается (новый консенсус). Responsive: выход за VA без поддержки → возврат в баланс. Основа динамической работы с профилем. → [[04_Market_Profile/Initiative_vs_Responsive]]
- **Composite Profile** 🟢 — объединённый профиль нескольких сессий в единый аукцион (при перекрытии VA/POC и отсутствии трендовых дней). Уровни остаются актуальными дольше отдельной сессии. → [[04_Market_Profile/Composite_Market_Profile]]
- **Статический / Динамический** 🟢 — два подхода к торговле. Статика: неизменные правила + доверие бэктесту/математике. Динамика: решения исходя из уникальности каждой ситуации, требует тысячи часов опыта. Гибрид: статический контекст (PDH/PDL → направление) + динамический набор позиции (выбор модели входа). → [[01_Concepts/Static_vs_Dynamic]]
- **Тайминги** 🟢 — временны́е окна активности/неактивности сессий и макросов. Включают сессионные тайминги (Kyiv UTC+2/+3) и ICT Macros (7 окон). → [[05_Sessions_Timings/Session_Dynamics]] · [[05_Sessions_Timings/ICT_Macros]]
- **Топ / Дно** 🔴 — локальный / глобальный экстремум.
- **Тренд / Контртренд** 🔴 — направление основного движения / против него.
