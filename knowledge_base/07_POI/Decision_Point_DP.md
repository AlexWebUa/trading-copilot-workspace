# Decision Point (DP)

**DP** (Decision Point) — ключевая точка графика, от которой ожидается реакция для понимания: продолжит ли цена текущий контекст или инвертирует его. Контекстная точка принятия решения.

Основная форма DP: **имбаланс (FVG)** — именно неэффективность показывает силу той или иной стороны рынка.

## Два сценария

| Сценарий | Описание |
|---|---|
| **Уважение DP** | Цена реагирует от DP → продолжает текущий контекст |
| **Инверсия DP** | Цена пробивает DP → зона меняет функцию и становится POI для противоположного направления |

**Пример**: лонговая DP инвертирована → она становится зоной для набора шортовых позиций.

## Применение по таймфреймам

| Контекст | ТФ | Назначение |
|---|---|---|
| **Глобальный** | 4H / 1D | Строить глобальные таргеты и план доставки цены на неделю/месяц |
| **Интрадей** | 30M / 1H | DP — неэффективности, сформированные в рамках текущей сессии |

В рамках каждой сессии образующаяся DP уважается и продолжает контекстное движение (если контекст правильно определён).
