# BOS — Break of Structure

Слом рыночной структуры — пробитие значимой структурной точки. Полноценный BOS меняет контекст; подтверждающий BOS (cBOS) лишь продолжает текущий. Подробный разбор типов:

## Swing (Context) BOS

Свинговый BOS — **«правильная»** отметка структуры для определения контекста рынка **исключительно через инструмент структуры**. Работает на крупных, значимых Key High / Key Low.

**Назначение**: ответ на вопрос «в каком контексте сейчас находится рынок».

## Fractal / Minor (Entry) BOS

Мелкий BOS, используемый:
1. Для **подтверждения точки/модели входа** в моменте.
2. Для работы **исключительно в моменте**, не учитывая контекстную (свинговую) структуру.

**Применение**: только во время рейдов высоколиквидных уровней — когда цена сняла ликвидность и нужен структурный триггер для входа.

> ⚡ Ключевая идея: при поиске моделей для входа после манипуляций достаточно ждать **перебития ближайшего лоя/хая** — не нужно дожидаться свингового BOS.

## cBOS (Confirmed / Continuation BOS)

**Подтверждение** текущей структуры. Отличие от обычного BOS — структура **не меняется**, а продолжает обновлять экстремумы в том же направлении. После cBOS — дождаться отката (коррекции) и продолжать работать по тренду.

## Сопоставление типов

| Тип | Размер экстремума | Смысл | Применение |
|-----|-------------------|-------|------------|
| **Swing BOS** | Key High/Low (крупный) | Смена контекста | Определение направления торговли |
| **Minor / Fractal BOS** | Локальный high/low | Триггер входа | Вход после снятия ликвидности |
| **cBOS** | Key High/Low | Продолжение тренда | Подтверждение работы по структуре |

## Практика

1. Определить контекст через свинговый BOS (где мы сейчас — тренд, разворот, консолидация).
2. Ждать рейда ликвидности на HTF POI.
3. Использовать Fractal/Minor BOS на LTF как триггер входа.
4. После входа контролировать cBOS для подтверждения продолжения структуры.
