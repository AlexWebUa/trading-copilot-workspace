# Multi-TF Analysis (многотаймфреймовый анализ)

Обязательный подход вне зависимости от стиля торговли: анализ **сверху вниз** — от старших таймфреймов к младшим. Все ТФ анализируются последовательно.

## Логика синхронизации ТФ

Младший ТФ всегда является **подструктурой** старшего. Это нормально и ожидаемо:

- HTF бычья структура (повышение HH/HL) → во время коррекций LTF будет выглядеть **шортово** (локальный даунтренд)
- Это не противоречие — LTF-коррекция = **RTO на старшем ТФ**

### Процесс синхронизации

1. HTF устанавливает новый хай → начинается коррекция
2. LTF (15M) ломает структуру вниз → локальный нисходящий тренд
3. HTF (4H) при этом остаётся восходящим — контекст не изменился
4. Когда HTF приходит к зоне интереса → MS на 15M **разворачивается и синхронизируется** с HTF
5. Новый импульс вверх → цикл повторяется

### Признак слома HTF-структуры

Если во время коррекции **LTF не может синхронизироваться** со старшим ТФ (15M продолжает давить ниже) → это сигнал потенциальной смены свинг-структуры на HTF.

## Рабочие ТФ-пары

Рекомендуемый стек: **1D → 4H → 15M → 1M/5M (вход)**

| Назначение | ТФ |
|---|---|
| Глобальный контекст | 1D |
| Рабочий контекст / POI | 4H |
| Уточнение зоны / структура | 15M |
| Вход в позицию | 1M / 5M |

> Можно использовать 3H, 17M, 8H — но лучше придерживаться нескольких **чётких** ТФ и следовать им последовательно.

## Валидация POI через LTF

При подходе цены к HTF POI — переход на LTF для входа:
- Ждать **слома структуры на LTF** (Minor BOS) — подтверждение агрессии
- Если LTF не показывает агрессии и BOS не формируется → риск слома и на HTF → пропускать позицию

Зоны спроса/предложения валидируются совместно со структурой и мульти-ТФ контекстом. Слабые min/max = пулы ликвидности → цель для снятия перед BOS/cBOS.
