# Метод Вайкоффа

## Суть

Метод Ричарда Демиля Вайкоффа — подход к анализу рынка через действия крупного капитала («smart money»). Базируется на наблюдении за реальным поведением участников аукциона, а не на индикаторах.

Вайкофф работал на NYSE с 15 лет, что позволило ему изучить внутреннюю механику биржевых процессов.

## Два закона

### 1. Закон спроса и предложения
Цена формируется под влиянием спроса и предложения крупных игроков. Понимание их действий — ключ к успеху.

### 2. Закон причины и следствия
Каждая «причина» на рынке имеет «следствие»:
- Фаза [[#Accumulation|Accumulation]] (причина) → рост цены (следствие).
- Фаза [[#Distribution|Distribution]] (причина) → падение цены (следствие).

**Импликация**: чем слабее причина, тем слабее следствие. Закон определяет **потенциал** движения — масштаб следствия пропорционален масштабу причины.

## Фазы рыночного цикла

Цикл состоит из четырёх фаз. Каждая фаза делится на пять диапазонов: **A, B, C, D, E**.

### Accumulation
Фаза набора позиции крупным капиталом после нисходящего движения. Цена стабилизируется, формируется боковик, в котором smart money аккумулирует актив. См. [[Accumulation_Phase|детальный разбор Accumulation]].

### Re-accumulation
Повторная аккумуляция внутри существующего восходящего тренда — технический «отдых», во время которого крупный капитал добирает позицию перед следующим импульсом. См. [[Accumulation_Phase#Re-accumulation|Re-accumulation]].

### Distribution
Фаза фиксации прибыли: крупный капитал сбрасывает актив розничным участникам на максимумах. Цена формирует боковик перед нисходящим движением. См. [[Distribution_Phase|детальный разбор Distribution]].

### Re-distribution
Повторное распределение внутри нисходящего тренда. См. [[Distribution_Phase#Re-distribution|Re-distribution]].

## Структура диапазонов A–E

Каждая из четырёх фаз проходит через пять диапазонов **A → B → C → D → E**:

- **Phase A** — торможение предшествующего движения (появление первой встречной инициативы).
- **Phase B** — основной процесс (накопление или распределение актива) внутри диапазона с многоразовыми тестами.
- **Phase C** — последняя манипуляция: [[Accumulation_Phase#Phase C — последняя манипуляция|Spring]] в Accumulation / [[Distribution_Phase#Phase C — последняя манипуляция|UTAD]] в Distribution.
- **Phase D** — выход из диапазона: первые признаки направления ([[Accumulation_Phase#Phase D — выход из накопления|LPS + SOS]] / [[Distribution_Phase#Phase D — выход из распределения|LPSY + SOW]]).
- **Phase E** — Следствие: агрессивный выход в направленное движение.

Подробная анатомия каждого диапазона — в заметках [[Accumulation_Phase]] и [[Distribution_Phase]].
