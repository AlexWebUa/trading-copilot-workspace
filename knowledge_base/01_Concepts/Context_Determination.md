# Определение контекста

## Принцип

> «Цена движется от ликвидности к неэффективности» — _PashaTrltsk_.

Контекст — это понимание направления движения цены и зон, где цена может дать значимую информацию (точки изменения контекста). Любая сделка должна быть согласована с актуальным контекстом старшего таймфрейма (HTF).

Базовые инструменты определения контекста: **[[../03_Tools/Liquidity|Liquidity]]** + **[[../03_Tools/Imbalance|Imbalance]]** (неэффективность доставки цены).

## Иерархия таймфреймов

| TF | Назначение |
|----|-----------|
| **D1 (1M/1W)** | Глобальный контекст, глобальные таргеты. Анализ Order Flow, Imbalance, Liquidity. |
| **H4** | Глобальное понимание доставки цены. Иногда даёт больше информации, чем D1 (или наоборот). Используется параллельно с D1. |
| **H1** | Основной TF для работы внутри дня. Определение [[../03_Tools/Liquidity|sellside/buyside liquidity]], ключевые [[../07_POI/POI|POI]], триггеры и таргеты. |
| **M15 / M5** | Order Flow LTF. |
| **M5 / M3 / M1** | Точка входа, [[../08_Entry_Models/Entry_Models|entry models]]. |

## Синхронизация и рассинхронизация HTF/LTF

| Состояние | Условие | Поведение системы |
|-----------|---------|-------------------|
| **Синхронизация** | D1/H4 и H1 движутся в одну сторону | Лучшие условия. Можно тянуть позицию >1 рабочего дня. Только тейк/стоп — за чартом не следим. Можно открывать против рейда ликвидности. |
| **Рассинхронизация** | D1/H4 и H1 движутся в разные стороны (H1 — корректирующее движение) | Таргет — первый высоколиквидный пул. Средний RR < 2. Позиция должна быть закрыта до London Close, иногда раньше. Сопровождение позиции вручную. |

## Логика работы внутри дня (на примере NAS100/SP500)

1. **D1 BIAS** (long или short).
2. **H4–H1 контекст** — Order Flow, рейды ликвидности, тесты [[../03_Tools/Rejection_Block|RB]], ребалансы [[../03_Tools/FVG|FVG]].
3. **Синхронизация D → H?**
4. **Invalidation Point** (точка отмены сценария).
5. **NYM logic** — [[#Power-of-Three|PO3]] на сессии New York Manipulation.
6. **Session Narrative** — нарратив сессии (Asia → London → NY).
7. **Manipulation + Target** — какая ликвидность снимется как манипуляция и куда пойдёт цена дальше.

## Триггеры и таргеты на H1

В рамках одного дня:
- **Триггер** для набора позиции: ключевой POI или пул ликвидности (тестирование/снятие).
- **Таргет** для фиксации: следующий высоколиквидный пул или внутренняя [[../03_Tools/Liquidity|liquidity]].

## Модели на LTF (M15/M5/M1)

| Сценарий | Триггер | TF входа |
|----------|---------|----------|
| HTF Liquidity Grab | Снятие ликвидности на HTF → IOF | M15 → M5 |
| POI Test | Тест внутреннего POI → IOF | M5 → M5 |
| Internal Liquidity Grab | Снятие внутренней ликвидности | M5 → M1 |

## Виды POI

POI = область инициативы. Включает:
- **Inefficiency (всех типов)**: [[../03_Tools/FVG|FVG]] · [[../03_Tools/IFVG|IFVG]] · [[../03_Tools/BPR|BPR]] · [[../03_Tools/GAP|GAP]] (механизм — [[../02_Market_Structure/Price_Delivery_Rebalancing|Rebalancing]])
- **Blocks (всех типов)**: [[../03_Tools/Order_Block|OB]] · [[../03_Tools/Breaker_Block|BB]] · [[../03_Tools/Rejection_Block|RB]] (механизм — [[../03_Tools/Mitigation_Block|Mitigation]])

## Глобальная статистика времени трейдера

> 90% времени мы находимся в **неопределённости с контекстом**, 9% — в **ожидании позиции**, и только 1% — в **позиции**.

## Power of Three (NYM Logic)

В рамках NYM-сессии используется концепция [[../05_Sessions_Timings/PO3_AMD_Sessions|PO3 / AMD]]: Accumulation → Manipulation → Distribution. NYM также используется как уровень поддержки/сопротивления:
- Аккумуляция позиции **под** уровнем,
- Дистрибуция — **над** уровнем.

## Глобальные правила контекста

См. [[../00_Index/_Global_Rules]] · раздел "Контекст и подход".

| Правило | Источник |
|---------|----------|
| Любая сделка строится в контексте недельного движения | Bellissimo ([[../09_Setups/1h3m_by_Bellissimo]]) |
| 1H — основной TF для интрадей | PashaTrltsk |
| HTF Liquidity Grab → ожидание разворота, IOF на LTF | Context.md (автор не указан) |
| При синхроне можно открывать против локального рейда | PashaTrltsk |
| При рассинхроне закрытие до London Close | PashaTrltsk |
