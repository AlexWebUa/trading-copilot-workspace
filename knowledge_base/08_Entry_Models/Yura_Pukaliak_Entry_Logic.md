# Entry Logic — Yura Pukaliak

Авторская логика входа (конспект, с любовью для DT FAMILY).

## Базовая модель

Рабочий пример: D1 TF · **GBPUSD**.

### Два ключевых элемента модели

1. **Снятие ликвидности** (liquidity grab).
2. **Поглощение движения**, которое привело к снятию.

## Работа с имбалансом (FVG)

После срабатывания модели переход на LTF: **M5 / M15** для наблюдения за формированием входа.

### Зависимость TF входа от TF снятия

| TF снятия | TF входа |
|-----------|----------|
| H4 | M15 |
| H1 | M5 |

### Валидация FVG

- Требуется **закрытие фитилём** в нужной зоне как фактор валидации модели.
- Уровень **0.5 FVG** — ключевой: важно как закрываются свечи от него. Если следующая свеча закрепляется над свечой, которая тестировала 0.5 FVG (на H4 TF) — имбаланс показывает силу и валидность.
- На HTF (H4) важно наблюдать **как формируются свечи**, а не только факт касания.

### Поведение в имбалансе

В имбаланс не всегда приходит инверсия → используется **HTF-контекст** и базовая модель (см. выше). Дополнительных подтверждений внутри имбаланса не ждут — ловят движение в самом начале; в имбалансе уже принимают решение (редкий выход из позиции).

> **Ключ**: правильное определение [[../01_Concepts/Context_Determination|контекста]]. Без него модель не работает.

## Правила входа

| Правило | Значение |
|---------|----------|
| Вход | Только **после закрытия свечи** (не в процессе формирования). |
| Подтверждения | Не ждём доп. подтверждений после модели — движение ловим с начала. |
| Выход по встрече со встречным имбом | Редко выходит из позиции. Если на H1 есть встречный имбаланс и цена его встретила с формированием модели — выход. |
| Break-Even (BE) | **Не использует**, кроме случаев выхода новостей. Обоснование: вылет в BE и уход к таргетам морально переносится хуже, чем классический стоп. |
| Снятый PDH/PDL | Не является причиной для скипа — **контекст приоритетнее**. |
| 30m TF | **Не используется**. |

## Торгуемые инструменты

- **GER40** (DAX)
- **Forex**
- **XAUUSD** (золото) — чаще в Лондон; Франк торгуется при достаточном количестве факторов.

## Позиции в «нестандартное» время

- **Lunch / Pre-NY**: если аккаунт в плюсе — торгует (имеется в виду: не закрывает позицию с началом Lunch).
- **Открытие месяца / квартала**: скип (пример: 01.04).

## Чего не использует

- **Order Block** (OB) — не использует вообще.
- **Break-Even** — не использует (кроме новостей).
- **30m TF** — не использует.

## Работа с DXY

Использует — тот же анализ, что и на других инструментах: проверка синхрона EUR/DXY (или другого инструмента).

## Работа с FTA против позиции

**FTA** (First Trouble Area) — ближайшая преграда. Вопрос: смущает ли FTA как H4 FVG против позиции?
- Для **свинг-позиции** — да, наблюдает как цена работает с FTA.
- Для интрадей — зависит от контекста.
