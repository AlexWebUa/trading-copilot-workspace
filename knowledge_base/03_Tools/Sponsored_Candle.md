# Sponsored Candle (SC)

**Спонсированная свеча (SC)** — свеча, которая **сняла ликвидность**. По разметке идентична [[Order_Block|OB]], но **обязательно связана со снятием ликвидности**.

## SC vs OB

| Параметр | OB | SC |
|----------|----|----|
| Снятие ликвидности | Не требуется | **Обязательно** |
| Разметка | Последняя противоположная свеча перед импульсом | Идентично + факт снятия пула |
| Приоритет в системе | Ниже | **Выше** (приоритетная зона) |

## Практическое правило

> В системе **классический OB не используется**. Приоритет отдаётся **SC** — зонам, которые сняли ликвидность.

Логика: снятие ликвидности = **явный след крупного игрока**. OB без снятия ликвидности слабее, может быть **случайной структурой**.

## Разметка

1. Найти **свечу, снявшую локальный пул ликвидности** (BSL или SSL).
2. Отметить её диапазон как **SC-зону** (по аналогии с OB).
3. Проверить **IMB после SC** (желательно наличие [[FVG]]).
4. Работать как с обычной зоной спроса/предложения.

## Связанные заметки

- [[Liquidity]] — пул, который снимает SC
- [[FVG]] — IMB после SC
- [[Breaker_Block]] · [[Mitigation_Block]] · [[Rejection_Block]] — родственные зоны
