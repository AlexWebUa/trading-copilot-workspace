# Propulsion Block (PB)

**Propulsion Block (PB)** — дополнительная рабочая зона, которая формируется **внутри или рядом с [[Order_Block|Order Block]]** в момент ретеста, после чего цена получает новое импульсное продолжение. По сути это вторичная точка подтверждения силы исходного блока: если Order Block — базовая область интереса, то PB появляется уже в момент реакции от неё.

## Формирование

1. Цена приходит в Order Block.
2. Внутри зоны получает реакцию.
3. Появляется новая свеча/диапазон, от которого начинается следующий импульс — это и есть Propulsion Block.

По сути это два последовательных блока: первоначальный Order Block и новый локальный блок, подтверждающий продолжение движения. PB отражает, что рынок не просто отреагировал от старшей зоны, а удержал её и создал новый слой спроса/предложения внутри движения.

## Почему используется

Часто даёт более точную точку входа, чем широкий исходный Order Block, поскольку формируется **после** первой реакции рынка:
- сокращает стоп;
- даёт более понятную структуру для входа;
- вход происходит после подтверждения, а не в первое касание — по продолжению уже начавшегося импульса.
