# Fair Value Gap (FVG / Imbalance)

**FVG / Imbalance** — ценовой дисбаланс: диапазон на графике, где было заложено **мало ликвидности**. Возникает при сильном импульсном движении свечи, которое цена **почти всегда возвращается перекрывать** (ребалансировать).

> Аналогия: покраска стены валиком сверху вниз оставляет пустоты. Чтобы закрыть их — нужно провести валиком снизу вверх. Тот же принцип у FVG — рынок возвращается закрывать неэффективность.

## Геометрия формации

**Три свечи**, одна из которых импульсная:
1. Найти три свечи с явной импульсной серединой.
2. Через инструмент «Коррекция по Фибоначчи» натянуть от **фитиля первой свечи** до **фитиля последней**.
3. Полученный диапазон — и есть FVG.

### Условие существования FVG

FVG **существует только тогда, когда фитили первой и третьей свечи не перекрываются** — между ними есть реальный ценовой разрыв. Если фитиль третьей свечи заходит в диапазон фитиля первой, имбаланс уже частично закрыт и FVG-зоны нет.

| Тип | Условие |
|-----|---------|
| **Бычий FVG** | Low свечи 3 > High свечи 1 (разрыв снизу вверх) |
| **Медвежий FVG** | High свечи 3 < Low свечи 1 (разрыв сверху вниз) |

Если это условие не соблюдено — перед вами обычная коррекция без имбаланса, не FVG.

## Глубина перекрытия

| Тип перекрытия | Смысл |
|----------------|-------|
| **Full Fill** (100%) | Полная ребалансировка |
| **0.5** (50%) | Наиболее частый вариант на реальном графике — реакция от середины FVG (см. [[../02_Market_Structure/Price_Delivery_Rebalancing#Уровни реакции внутри FVG|C.E.]]) |

## Двойная роль FVG

| Применение | Что делает |
|------------|------------|
| **Определение контекста** | FVG на старшем ТФ = POI, внутри которого ищем факторы для набора позиции |
| **Модель входа** | Мелкий FVG на LTF после манипуляции служит точкой входа |

## Синхронизация таймфреймов

Для успешной работы с FVG должна соблюдаться синхронизация:

- 4H + 1H
- 4H + 30M
- 1H + 15M
- 15M + 5M
- и т. д.

### Пример связки 4H + 30M

1. На 4H цена движется в шортовом Order Flow, POI = 4H FVG.
2. При заходе цены в 4H FVG переходим на 30M.
3. На 30M видим вложенный FVG **внутри** 4H FVG.
4. Внутри 30M FVG происходит манипуляция → открываем позицию.

> Если торгуется эта связка — **не обязательно** наличие слома рыночной структуры: слом произошёл раньше, работа ведётся уже **внутри** движения.
