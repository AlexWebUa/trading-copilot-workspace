# GAP

**GAP** — один из видов ценового дисбаланса: пустая область между экстремумами свечей, образующаяся на **открытии рынка после выходных** (или после крупного перерыва в торгах).

## Разметка на графике

Формируется из **двух свечей**, между которыми остаётся пустота-разрыв. Через инструмент «Коррекция по Фибоначчи» натягивается:
- **от конца первого экстремума свечи**
- **до начала следующего**.

## Применение

Как и другие виды ценовых дисбалансов, GAP используется:
- **В определении контекста** — на старшем ТФ выступает POI, внутри которого ищутся факторы для набора позиции.
- **В модели входа** — точечно на LTF.
