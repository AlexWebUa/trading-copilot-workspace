# Inducement (индюсмент)

**Inducement** — вид ликвидности, расположенный вблизи границ зоны интереса (POI). Используется как «приманка» для движения цены: заставляет её протестировать POI глубже и одновременно служит дополнительным топливом для разворотного движения. Помогает выявить более релевантные POI — те, перед которыми есть индюсмент, приоритетнее тех, где его нет.

## Вариации

**FVG с перекрытием менее 50%** — неполный тест зоны. Считается потенциальным индюсментом: цена вернётся для более глубокой ребалансировки.

**Локальный / минимальный тест POI** — цена лишь слегка касается зоны без полного заполнения. Ожидается возврат внутрь POI.

**Дистрибьюция/аккумуляция перед POI** — консолидация у границы зоны. Вариация второго сценария: цена «топчется» у POI, формируя локальную ликвидность перед реальным входом.

**STH/STL** — краткосрочные свинги (Short-Term High/Low) часто выступают индюсментом для будущего среднесрочного движения. Цена снимает STL/STH как «приманку», после чего формирует ITL/ITH и разворачивается.

> Всегда ждать снятия индюсмента перед POI — позиция без снятия индюсмента несёт повышенный риск BE/стопа на перетесте.
