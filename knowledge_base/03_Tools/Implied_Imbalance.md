# Implied Imbalance (ImpIMB)

**Implied Imbalance (ImpIMB)** — агрессивный ценовой дисбаланс, порождённый спросом покупателей/продавцов. В отличие от классического [[FVG|FVG/IMB]], импульс здесь **перекрывается длинными фитилями с обеих сторон** — визуально зона менее очевидна, чем обычный FVG.

## Разметка на графике

Формация строится из **трёх свечей**, где импульс средней свечи обязательно перекрыт фитилями с правой и левой стороны. Через **«Коррекция по Фибоначчи»** поочерёдно выделяется фитиль с обеих сторон; диапазон между уровнями **0.5** каждого фитиля — и есть Implied Imbalance.

## Применение

Как и другие типы ценового дисбаланса — используется и для определения контекста, и как модель входа (см. [[../02_Market_Structure/Price_Delivery_Rebalancing]]). На старшем ТФ выступает как [[../07_POI/POI|POI]], внутри которого ищутся факторы для набора позиции.
