# Order Block (OB)

**Demand Zone / Supply Zone** — зоны на графике, от которых рассматривается вход в позицию. В рамках системы изучаются **три типа**:

- **OB** — Order Block.
- **SC** — [[Sponsored_Candle|Sponsorship Candle]].
- **STB / BTS** — [[../09_Setups/STBBTS|Sell-to-Buy / Buy-to-Sell]].

Все они концептуально близки, но имеют различия в механике.

## Что такое OB

**Order Block** — свеча, внутри которой находятся **отложенные ордера умного капитала**. После формирования такой свечи крупный игрок возвращается её тестировать, потому что набрать всю позицию за один раз невозможно.

### Визуально
- **Bullish OB** — последняя **красная** (нисходящая) свеча перед ростом.
- **Bearish OB** — последняя **зелёная** (восходящая) свеча перед падением.

## Правила использования

### 1. Контекст структуры ([[../02_Market_Structure/Market_Structure|Market Structure]])
OB должен работать **в контексте текущей структуры**. Восходящая структура → подбирать только **бычьи** OB. Нисходящая → только **медвежьи**.

### 2. IMB после OB
После формирования OB желательно увидеть **имбаланс** ([[FVG]]). Имбаланс указывает на агрессию покупателя/продавца → подтверждает **истинность** движения. Отсутствие IMB после OB снижает качество зоны.

### 3. Отсутствие встречной ликвидности за OB
При подборе OB проверять, что **за зоной нет ликвидности**, которая может притянуть цену и выбить по стопу.

## OB как сбалансированный диапазон

На примере движения **BTS**: видим Buyside-доставку вверх (разрыв справедливой стоимости), затем Sellside-delivery поглощает прошлое движение → получается **сбалансированный участок** графика. По такому принципу формируются **все** зоны спроса/предложения:

1. Импульсное движение в одну сторону (оставляет FVG).
2. Встречное движение возвращается для ребалансировки.
3. В точке встречи формируется сбалансированная зона — это и есть будущий OB / supply-demand zone.

Та же логика зеркально работает для медвежьего OB.
