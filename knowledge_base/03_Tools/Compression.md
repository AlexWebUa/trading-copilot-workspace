# Compression (LRLR — Low Resistance Liquidity Run)

**Компрессия** — пример **трендовой ликвидности**. Сжатие ценового диапазона приводит к **эффективной доставке цены** (движение без FVG или с минимальными разрывами) в локальную область.

## Механика

- Движение к локальным целям + **билдинг ликвидности по одну сторону** от компрессии.
- После снятия локальных целей (ликвидность собрана) **вся LRLR** становится причиной движения цены в **обратную сторону**.
- Цена обычно **агрессивно поглощает** всю компрессионную структуру.

## Интерпретация

| Школа | Восприятие компрессии |
|-------|------------------------|
| Классический ТА | Линия **сопротивления** / поддержки |
| Smart Money | **Скопление ликвидности** (не более) |

## Практический вывод

**Компрессия = отличная цель для сделки.** При анализе:
- **Против** компрессии (внутри неё) — обычно слабое, с малой волатильностью движение цены.
- **После** снятия локальной цели — ожидать обратного агрессивного движения через всю компрессию.
