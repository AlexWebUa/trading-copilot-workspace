# Inversion Fair Value Gap (IFVG)

**IFVG** — ценовой дисбаланс, аналог обычного [[FVG|Imbalance/FVG]], который был **полностью прошит/проигнорирован** ценой. После прошива зона меняет функцию (поддержка ↔ сопротивление).

## Разметка на графике

Через инструмент **«Коррекция по Фибоначчи»** выделяется FVG, который цена проигнорировала/прошила. Этот прошитый FVG и есть **IFVG**.

### Критическое различие с BPR

| Условие | Результат |
|---------|-----------|
| FVG прошит **любым движением** (ценой, без формирования встречного FVG) | **IFVG** |
| FVG прошит **другим встречным FVG** (наложение противоположного FVG) | **[[BPR]]** (Balanced Price Range) |

⚠️ Это принципиальное различие: IFVG — одиночный прошитый FVG, BPR — пересечение двух разнонаправленных FVG.

## Применение

IFVG, как и другие типы дисбалансов, используется:
- **В определении контекста** — POI на старшем ТФ, в котором ищем факторы для набора позиции.
- **В модели входа** — после взаимодействия с IFVG и реакции на LTF.
