# Глобальные правила торговой системы

Сводный документ по правилам, применимым ко **всем** инструментам и сетапам. Правила для конкретных инструментов — в [[../10_Instruments/_Index|10_Instruments]]. Авторская атрибуция указана где есть расхождения.

> Документ актуализируется по мере обработки исходников. Source: Group 1 (Concepts).

---

## 1. Контекст и подход

| Правило                                                                                 | Источник                                                 |
| --------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| Цена движется от **ликвидности к неэффективности**                                      | _PashaTrltsk_ → [[../01_Concepts/Context_Determination]] |
| Базовые инструменты определения контекста: **liquidity + imbalance**                    | _PashaTrltsk_                                            |
| Любая сделка строится **в контексте недельного движения** (не случайно в центре сессии) | _Bellissimo_ → [[../09_Setups/1h3m_by_Bellissimo]]       |
| Основа — **факт**, а не догадка («хочу, чтобы это сняли» — антипаттерн)                 | _Bellissimo_                                             |
| Идти за актуальным трендом, даже если он оставляет за собой **компрессию**              | _Bellissimo_                                             |
| 90% времени — неопределённость, 9% — ожидание, 1% — в позиции                           | _PashaTrltsk_                                            |
| Любая модель работает только при **правильно определённом контексте**                   | _Yura Pukaliak_                                          |

## 2. Multi-TF анализ

| Правило | Источник |
|---------|----------|
| **D1** — глобальный контекст и таргеты на неделю | универсально |
| **H4** — синхронизатор и доп. слой к D1 | _PashaTrltsk_ |
| **H1** — основной TF для интрадей | _PashaTrltsk_, _Bellissimo_ |
| **M15/M5** — Order Flow LTF | _PashaTrltsk_ |
| **M1/M3/M5** — точка входа | _PashaTrltsk_, _Bellissimo_ (M3) |
| TF входа зависит от TF снятия: H4 → M15 · H1 → M5 | _Yura Pukaliak_ |
| **Синхронизация** D1/H4 ↔ H1 → можно тянуть позицию >1 дня, не следить за чартом, входить против локального рейда | _PashaTrltsk_ |
| **Рассинхронизация** → таргет = первый высоколиквидный пул, RR < 2, закрытие до London Close | _PashaTrltsk_ |
| 30M TF не используется | _Yura Pukaliak_ |

## 3. POI и зоны

| Правило | Источник |
|---------|----------|
| **POI** = inefficiency (FVG/IFVG/BPR/GAP) ИЛИ blocks (OB/BB/RB) | универсально |
| Inefficiency → механизм **rebalancing** | универсально |
| Blocks → механизм **mitigation** | универсально |
| OB не используется (вариант) | _Yura Pukaliak_ |
| См. подробнее: [[../07_POI/POI]] | — |

## 4. Вход в сделку

| Правило | Источник |
|---------|----------|
| Вход **только после закрытия свечи**, не в процессе формирования | _Yura Pukaliak_ |
| Вход **маркетом**, иногда на тесте | _Bellissimo_ |
| Не ждать дополнительных подтверждений после модели — ловить движение в начале | _Yura Pukaliak_ |
| Свип ликвидности — обязательный триггер | _Bellissimo_ |
| Для LONG: 3m BOS выше рейда; для SHORT: 3m BOS ниже рейда | _Bellissimo_ |
| Ликвидность снимается **без закрепа** на H1 (только свип) | _Bellissimo_ |

## 5. Управление сделкой (BE, выходы, развороты)

| Правило                                                                                | Источник                      |
| -------------------------------------------------------------------------------------- | ----------------------------- |
| **Без Break-Even** (вылет в BE и уход к таргетам морально хуже стопа; малая амплитуда) | _Yura Pukaliak_, _Bellissimo_ |
| Исключение: **BE при выходе новостей**                                                 | _Yura Pukaliak_               |
| Тянуть на **ближайшую ликвидность**, а не «куда хочется»                               | _Bellissimo_                  |
| Цель **не ставится на переснятие ликвидности**                                         | _Bellissimo_                  |
| При FTA до таргета — сброс основной части позиции                                      | _Bellissimo_                  |
| При синхроне — только тейк/стоп, не следим за чартом                                   | _PashaTrltsk_                 |
| При рассинхроне — ручное сопровождение позиции                                         | _PashaTrltsk_                 |
| Закрытие позиции до **London Close** при рассинхроне                                   | _PashaTrltsk_                 |
| Тянуть позицию >1 рабочего дня — только при синхроне                                   | _PashaTrltsk_                 |

## 6. Сессии и тайминги (когда торгуем / когда пропускаем)

| Правило                                                         | Источник          |
| --------------------------------------------------------------- | ----------------- |
| **OTT** (Optimal Time Trade) = 09:00–17:00 по Киеву             | _Bellissimo_      |
| Абсолютные тайминги: **09:00, 15:00, 17:00** (Киев)             | _Bellissimo_      |
| Сессионные/контекстные тайминги (12, 14...) — не использует     | _Bellissimo_      |
| NAS100/SP500 — только в **NY AM/PM** (не Asia/London)           | _Context.md (UA)_ |
| DOW30 — когда на NAS100/SP500 непонятный контекст               | _Context.md (UA)_ |
| **Открытие месяца / квартала** — скип                           | _Yura Pukaliak_   |
| **Lunch / Pre-NY** — позицию не закрываем, если аккаунт в плюсе | _Yura Pukaliak_   |

## 7. Работа с ликвидностью

| Правило                                                                             | Источник        |
| ----------------------------------------------------------------------------------- | --------------- |
| Снятый PDH/PDL — **не** причина для скипа, контекст приоритетнее                    | _Yura Pukaliak_ |
| Свип фрактала **актуального дня** — фактор набора; свип фрактала прошлого дня — нет | _Bellissimo_    |
| Рейд должен быть качественным — пересечение с большим пулом                         | _Bellissimo_    |
| HTF Liquidity Grab → ожидание разворота, IOF на LTF                                 | _Context.md_    |
| При синхроне можно открывать **против** рейда ликвидности                           | _PashaTrltsk_   |
| NYM — ключевой уровень: аккумуляция под, дистрибуция над                            | _Context.md_    |

## 8. Причины для скипа сделки

| Причина | Источник |
|---------|----------|
| Отсутствие грамотного тейка (FTA близко к точке входа) | _Bellissimo_ |
| Отсутствие рейда ликвидности | _Bellissimo_ |
| Отсутствие модели m3m3 на LTF | _Bellissimo_ |
| Выход новостей | универсально |
| Закреп на H1 при снятии ликвидности (разрешён только свип) | _Bellissimo_ |
| Позиция против контекста | универсально |
| Окончание OTT (после 17:00 Киев) | _Bellissimo_ |
| BOS слишком далеко → неподходящий RR | _Bellissimo_ |
| Открытие месяца/квартала | _Yura Pukaliak_ |
