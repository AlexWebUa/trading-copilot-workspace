# DT15 / DT16 (FVG Rebalance + Advanced Structure)

Методология работы с POI через FVG-ребаланс (DT15) и с IOF через Advanced Structure — STL/STH/ITH/ITL (DT16). Оба файла от одного автора (frill-fur-214); дополняют друг друга.

> Применимо в первую очередь для **Classic Buy/Sell Day** (трендовых дней).

---

## DT15: Работа с POI через FVG-ребаланс

### Ключевые правила FVG-теста

- **Идеал**: полное перекрытие (100% / FullFill).
- **Достаточно**: перекрытие ≥ 50% C.E. — от этих значений можно рассматривать позицию.
- **Допустимо**: цена прошивает IMB выше/ниже — при условии, что нет закрепления телом (только тенью).

### Алгоритм (8 шагов)

1. Валидация POI.
2. Оценка коррекции/движения к POI.
3. Проверка условий FVG (50%+ или FF).
4. Ожидание **Displacement** — импульсного слома структуры, формирующего FVG (первые реакции: 3M–5M).
5. Дождаться теста/ребалансировки POI/IMB.
6. Получить FVG / cBOS.
7. LG (Liquidity Gap) / Inducement внутри FVG → переход на LTF (1M–3M) для поиска модели.
8. Вход по LTF-модели.

### После достижения цели

Оценить движение с HTF: если оно формировалось по описанной схеме → на HTF в любом случае останется FVG → это **следующая зона интереса (DP)**. Далее — та же логика заново (рекурсия).

## DT16: Advanced Structure для IOF (STL/STH/ITH/ITL)

### STL / STH = Fractal Swing Highs/Lows

Краткосрочные экстремумы (Short-Term Low/High) — базовые единицы структуры на LTF.

### Правила валидации ITL/ITH

1. **Графически виден** (визуально выраженный локальный экстремум).
2. **Снимает ликвидность**.
3. **Формирует импульсное движение + FVG** после.
4. STL в дальнейшем **перекроет** (ребалансирует) сформированный IMB.

### Критическое правило: ждать 3-й STL

> **Всегда ждать формирования 3-го STL!**

Первые 1–2 STL могут быть «топливом» для дальнейшего движения — входить на их BOSе опасно (цена использует их как внутреннюю ликвидность, а не разворачивается).

### Исключение: ITL без снятия ликвидности

ITL может формироваться **без снятия ликвидности**, если зарождался **внутри имбаланса** (FVG). В таком случае снятие заменяется ребалансировкой.

### FVG-правило (DT16)

Минимально необходимо **50% перекрытие FVG** (C.E.), идеал — FullFill.
