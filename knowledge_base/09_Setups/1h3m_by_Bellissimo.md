# Сетап 1h3m — Bellissimo

Авторский сетап Bellissimo (конспект 19.02.2024 + версия «For Students»).

> Do Your Own Research. Сетап представлен не для Copy+Paste, а как фреймворк, который каждый адаптирует под себя.

## Компоненты сетапа

Сетап строится на **3 факторах**:

1. **A-to-B Concept** — понимание движения от точки A (инициатива) к точке B (таргет).
2. **Технический конфирм** — сигнал на LTF.
3. **Структуризация** — технические ограничения, контролирующие визуальный расфокус. Например: работа только с одним TF (1H).

### Принципы
- Основываться на **факте**, а не на догадке.
- Идти за актуальным трендом, даже если он оставляет за собой [[../03_Tools/Compression|компрессию]].
- Не строить потенциальных догадок («А я хочу, чтобы это сняли»).

## Параметры

| Параметр | Значение |
|----------|----------|
| **OTT** (Optimal Time Trade) | 09:00–17:00 по Киеву |
| **TF контекста** | 1H (фундаментальная работа) |
| **TF входа** | 3M (вход в позицию); 5M — для более чистого графика |
| **TF HTF-контекста** | 1D — общий контекст на неделю |
| **TF BSL/SSL** | H1 (иногда H4 — для чёткой отметки ликвидности) |
| **Таймер сессий** | **Не используется** |
| **Контекстные тайминги (12, 14 и т. д.)** | **Не используется** |
| **Абсолютные тайминги** | 09:00, 15:00, 17:00 (по Киеву) |
| **Риск** | 2% |
| **Целевой RR** | 1.5–2.0 |
| **Winrate** | 75% |
| **Частота сделок** | ~3 в месяц |
| **Ожидаемая доходность** | +7–8% к депозиту в месяц |
| **Break-Even (BU)** | **Не используется** (амплитуда сделок небольшая) |
| **Вход** | Маркетом (возможно на тесте) |

## Контекст

Контекст = чёткое понимание направления цены, зон на чарте, где цена может дать важную информацию, и точек изменения контекста.

> Любая сделка должна быть **в контексте с недельным движением** чарта. Недельное движение = поток дней, не просто случайная точка в центре Лондонской сессии.

Позиция набирается **только при свипе фрактала актуального дня**. Свип фрактала прошлого дня — **не** фактор набора.

## Raid (рейд ликвидности)

Рейд ликвидности должен быть **качественным** — с учётом контекста и пересечением с большим пулом ликвидности. Плохой рейд = отсутствие снятия большого количества ликвидности → скип.

## Чек-лист набора позиции

1. **Свип ликвидности** в сторону контекста.
2. **3m BOS** на крайнем фрактале.
3. Для **LONG**: 3m BOS находится **выше** рейда.
   Для **SHORT**: 3m BOS находится **ниже** рейда.
4. Ликвидность снимается **без закрепа на 1H TF** — разрешён только свип (не закрепление).
5. В случае достижения **FTA** — сбрасывается основная часть позиции.
6. Цель **не ставится на переснятие ликвидности**.

## Targeting

Трейд тянется **на ближайшую ликвидность**, а не туда, куда «хочется». Принцип — логичный тейк, логичный вход, логичный стоп.

## Management

- **Без BU** — из-за малой амплитуды сделок инструмент BE удалён полностью.
- **В случае FTA перед таргетом** — сброс основной части.

## Причины для скипа

1. Отсутствие грамотного тейка (FTA слишком близко к точке входа).
2. Отсутствие рейда ликвидности (см. правила выше).
3. **Отсутствие модели m3m3 на LTF** (простейший фактор).

## Отменные факторы (красные флаги)

- Выход новостей.
- **Закреп на 1H TF** при снятии ликвидности (разрешён только свип).
- Позиция против контекста.
- Окончание OTT (после 17:00 Киев).
- BOS находится слишком далеко → неподходящий RR.

## Философия

> «Постоянное, непрекращающееся обучение, тренирующее наш ум и расширяющее кругозор, ведёт к жизненно важному интеллектуальному обновлению».

Действия не повторяются ради техники. Техника подкрепляет логику, не заменяет её.

## Плюсы и минусы

| Плюсы | Минусы |
|-------|--------|
