# VWAP Стратегии (Basic + Advanced)

Практическое применение VWAP в торговле: от базовой логики поддержки/сопротивления до продвинутых техник. Дополняет теоретическую базу из [[../04_Market_Profile/VWAP|VWAP]].

## Базовые стратегии

### 1. VWAP как поддержка/сопротивление (трендовый режим)

- Цена **выше VWAP** → покупатели доминируют → откат к VWAP / STDEV1 = **потенциальная точка входа в лонг**.
- Цена **ниже VWAP** → продавцы доминируют → тест VWAP / STDEV1 = **потенциальная точка входа в шорт**.
- Пробой VWAP + ретест = сигнал начала нового тренда или подтверждение импульса.

### 2. Flat Phase (возврат к среднему)

В фазе баланса VWAP используется в связке с полосами стандартного отклонения (STDEV1 ±1σ / STDEV2 ±2σ):

- От **верхней границы** (+1σ / +2σ) → **вход в шорт**.
- От **нижней границы** (−1σ / −2σ) → **вход в лонг**.
- **TP**: уровень VWAP (Midpoint).

Логика: статистическое равновесие цены и объёма → mean reversion.

### 3. Flat → Trend Transition

Флетовая фаза переходит в трендовую. Типично для американских индексов: флет overnight (ETH) → трендовая фаза с началом RTH (16:30 Kyiv). Сигнал — выход за полосы STDEV2 с удержанием.

## Продвинутые стратегии

### 4. Anchored VWAP (Привязанный VWAP)

VWAP, закреплённый на конкретном событии или свече (например, решение FOMC, импульсный ход).

**Логика**: показывает, кто контролирует рынок **после** важного события.
- Цена удерживается выше Anchored VWAP → покупатели контролируют.
- Цена возвращается и уходит ниже → инерция угасает → разворот наиболее вероятен.

Платформа: TradingView (ручная настройка). Exocharts — расширенные возможности.

### 5. Naked VWAP

VWAP из прошлых сессий, к которому цена **не вернулась** после его формирования. «Непокрытый» уровень.

**Применение**:
- Вход по тренду → Naked VWAP предыдущей сессии/недели = **аргументированный уровень для TP**.
- Подход к Naked VWAP + реакция → **триггер для разворота**.
- Пробой Naked VWAP → **сигнал силы** в направлении пробоя.

> TradingView не позволяет автоматически продлевать Naked VWAP — отслеживать вручную или через Exocharts.

### 6. Market Profile + VWAP (Комбо)

Поиск пересечения ключевого уровня Market Profile (VAH / VAL / POC) с уровнем VWAP (Midpoint / STDEV).

**Зона пересечения = высоковероятная область реакции** и потенциального паттерна для входа. Мощный фильтр для отбора сделок.
