# Indices by ilysha

**Активы**: NQ1! (основной, все входы) · ES1! (только для оценки корреляции/SMT, сделки не открываются).

⚠️ Другая система, чем [[Isqra_Strategy|Стратегия Isqra]] — оба автора работают с NQ/ES через один Discord-канал, но это два разных набора правил (разные TF-каскады, разные инструменты, разные тайминги). Не путать.

## Тайминги (OTT, UTC+3)

10:00–12:00 · 16:30–19:00 · 21:00–23:00

## Контекст

Глобальное направление цены — приоритет; индексы преимущественно трендовый актив (в большинстве случаев лонг), но оценивается ситуативно по работе цены с 1D/4H зонами (основные ТФ для контекста). Реакция от первых проблемных зон допускает работу в реверс.

## Multi-TF каскад

| ТФ | Роль |
|---|---|
| **1D** | Глобальный контекст — куда хочет двигаться цена; если цена формирует зоны «за нас» — работать через них |
| **4H** | Основной ТФ для рассмотрения сделок; также используется для ребаланса зон 1D «против нас», чтобы продолжать контекстное движение |
| **1H** | После теста зон 4H — проверка FTA «против». Если FTA далеко и есть триггер входа → BE на FTA (при отсутствии зон для ребаланса «за нас»; если такие зоны есть — BE не ставится) |
| **15M** | Основной ТФ для открытия сделок — через тест его зон, стоп за 4H–1H. На NYSE-открытии возможна работа через 30M/15M–1M |

### Таблица ребаланса (TF → куда ребалансируется)

| ТФ | Ребаланс в |
|---|---|
| 1D | 1D/4H |
| 4H | 4H/1H |
| 1H | 1H/30M/15M |
| 30M | 30M/15M |
| 15M | 15M/5M |
| 5M | 5M/3M/1M |

> Ребаланс 15M→5M и 5M→1M — только при **контекстном** движении. Для реверса ждать 15M→15M, 5M→5M/3M.

## Инструментарий (по ТФ применения)

- **[[../03_Tools/FVG|FVG]]** — на всех ТФ.
- **[[../03_Tools/Rejection_Block|Rejection Block]]** — 1D/4H/1H/15M; также засчитывается тень, тестировавшая FVG на 4H–1H при сильной реакции.
- **Fractal** — на всех ТФ (индикатор фракталов для удобства).
- **FVL** (Fair Value Level) — 1D/4H/1H/15M.
- **IDM** (снятие фракталов в имбалансе) — 4H/1H/15M.
- **CISD** (слом по телу свечи) — 15M/5M/3M/1M.

## Управление позицией (BE)

BE ставится на первых проблемных зонах при отсутствии зон для ребаланса; может быть снят, если по ходу доставки цены формируются зоны «за нас». Если сделка дошла до цели, но RR не устраивает — BE и продолжение удержания независимо от наличия зон.

## Модели входа

- **Aggressive Entry на NYSE open (M1)**: при быстром тесте зон «за нас» — вход без модели, просто по реакции/закрепу M1-свечи (при отсутствии противоположных зон на M1/M3/M5). Реже — вход за 3-5 минут до NYSE при снятии 4H-1H фракталов/тесте зон + чистая реакция на M1.
- **Реверсивные сделки**: после ключевых снятий 1D-4H или теста зон тех же ТФ; цель — первые FTA 15M-1H; для входа нужен ребаланс проблемных зон 3-5M + формирование зоны «за нас» (достаточно 1M).

## Частые ошибки (из опыта автора)

- Долгая работа на 3M-1M без периодической проверки старших ТФ (5-15M+) → пропуск зоны со старшего ТФ.
- Игнорирование SMT из S&P 500 (второй актив триады) из-за нехватки RR в моменте.
- «Вера в один актив» — игнорирование вероятного реверса, если второй коррелирующий актив (ES) уже снял таргет/пришёл в проблемную зону, когда основной (NQ) ещё не достиг цели → в этом случае BE или фиксация, если позволяет RR.
- Открывать сделки «просто ради сделки» без зон поддержки на старших ТФ (1D/4H/1H) или без таргетов — недопустимо; исключение — скальп на NYSE open (16:30-17:00 UTC+3).
