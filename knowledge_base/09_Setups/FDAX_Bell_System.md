# FDAX Bell System

Внутридневная стратегия на FDAX (DAX фьючерс). Ловит направленный импульс после 09:00 CET, фильтруя сигнал через ADX дневного таймфрейма.

## Концепция

> После 09:00 ищем продолжение структуры (Break of Structure), подтверждённое слабым направленным движением по дневному ADX → входим на пробое фрактала → фиксируем риск стопом и временем.

Цель: поймать внутридневной импульс, но только если дневной тренд **не слишком сильный** (ADX < порог). В условиях слабого ADX пробой структуры менее вероятно окажется ложным или экстремальным.

## Параметры стратегии

| Параметр | Значение |
|---|---|
| Инструмент | FDAX (DAX фьючерс) |
| Платформа | TradeStation (EasyLanguage) |
| Окно входа | После 09:00 CET |
| Фильтр контекста | Дневной ADX < порог (конкретное значение оптимизируется) |
| Триггер входа | BOS — пробой фрактального максимума / минимума |
| Стоп | Фиксированный ($) |
| Выход | Тайм-стоп (time stop) |

## Логика фильтра ADX

Стратегия **не работает** в дни с сильным дневным ADX — в таких условиях пробой структуры несёт повышенный риск экстремального движения или ложного пробоя. Слабый ADX означает, что рынок находится в «нейтральном» состоянии, где импульс после BOS имеет более чистую природу.

## Выходы из позиции

Применяется комбинация:
- **Фиксированный стоп-лосс** — денежный риск задаётся заранее.
- **Тайм-стоп** — позиция закрывается по истечении N баров вне зависимости от результата.

_Конкретные параметры выходов в источнике не указаны — подлежат оптимизации._

## Неоднозначности

- Конкретный порог ADX в источнике не приведён.
- Таймфрейм для BOS / фрактала не уточнён (предположительно M1–M5).
- Детальная статистика бэктеста в источнике отсутствует.
