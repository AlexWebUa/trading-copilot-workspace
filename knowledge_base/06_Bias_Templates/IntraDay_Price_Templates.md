# IntraDay Price Templates (ICT)

**IntraDay Price Templates** — набор визуальных шаблонов ICT, описывающих ожидаемые внутридневные паттерны движения цены. Используется как вспомогательный инструмент для определения контекста и направления в NY-сессии.

## ⚠️ Статус: stub

Исходный файл содержит только текстовую преамбулу (≈3 абзаца) и 8+ ссылок на изображения с примерами по неделям (30.01–17.03). Изображения в базе знаний недоступны — скрейпер зафиксировал только URL-адреса.

**Чего не хватает:**
- Описания каждого шаблона (что изображено, логика модели).
- Каталога шаблонов с названиями.
- Условий применимости каждого паттерна.

**Предложение:** запросить у автора текстовое описание шаблонов или повторный экспорт с альтернативными описаниями изображений.

## Ключевые тезисы из текста

- Шаблоны — **вспомогательный инструмент**, не сигнал. Требуют понимания контекста внутри дня.
- Не все шаблоны совпадают с теоретическими моделями точь в точь — логика сохраняется, форма может отличаться.
- Паттерны наиболее применимы для **определения направления в NY-сессии**.
- Рынок цикличен и ходит от ликвидности до ликвидности; для каждого дня есть своя цель, и чтобы к ней прийти — что-то нужно снять.
