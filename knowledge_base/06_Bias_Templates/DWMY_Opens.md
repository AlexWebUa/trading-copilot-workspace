# DWMY Opens (DO / WO / MO / YO)

**DO / WO / MO / YO** — ценовые уровни открытия нового дня, недели, месяца и года. Служат точками отсчёта для оценки рыночного контекста и поиска паттернов PO3.

## Определения уровней

| Уровень | Период | Момент открытия |
|---|---|---|
| **DO** (Daily Open) | День | 00:00 NY (форекс/индексы) / 01:00 Kyiv для индексов / 03:00 Kyiv UTC (крипта) |
| **WO** (Weekly Open) | Неделя | Понедельник 00:00 (форекс/крипта) |
| **MO** (Monthly Open) | Месяц | 1-е число, 00:00 |
| **YO** (Yearly Open) | Год | Открытие первого торгового дня года |

> ICT: для некоторых периодов вводится «True Open» (например, открытие 2-го квартала как YO-альтернатива), но базовый уровень YO остаётся ключевой долгосрочной границей.

## Четыре базовых паттерна

### 1. Аккумуляция под уровнем открытия (бычий контекст)

Цена уходит ниже открытия → консолидируется → пробивает уровень снизу вверх → восходящий тренд.

| ТФ | Тайминги |
|---|---|
| Дневной | Asia/ранний London → консолидация под DO → NY: рост над DO |
| Недельный | Пн–Вт (иногда до Ср) под WO → Чт–Пт: импульс вверх |
| Месячный | 1–2 недели под MO → 3–4 неделя: выход вверх |

### 2. Дистрибуция над уровнем открытия (медвежий контекст)

Цена уходит выше открытия → консолидируется → пробивает уровень сверху вниз → нисходящий тренд.

| ТФ | Тайминги |
|---|---|
| Дневной | Asia/ранний London над DO → NY: разворот вниз под DO |
| Недельный | Пн–Вт над WO → Ср–Пт: снижение под WO |
| Месячный | 1–2 недели над MO → 2–4 неделя: импульс вниз |

### 3. Тест уровня открытия (ложный пробой)

Цена стремительно пересекает уровень открытия → немедленно разворачивается. Формирует длинный фитиль. Сигнал возможной смены направления.

| ТФ | Характерное время |
|---|---|
| Дневной | Открытие London или NY |
| Недельный | Четверг–пятница (часто на новостях) |
| Месячный | 2-я (иногда 3-я) неделя месяца |

### 4. Флип уровня открытия

Цена пересекает уровень → при возврате уровень меняет функцию (бывшая поддержка → сопротивление и наоборот). Сигнал смены тренда.

## Статистика и уточнения по недельному паттерну (ICT)

- При бычьей недельной перспективе — с вероятностью **~70%** минимум недели формируется в **понедельник, вторник или среду** (к NY-сессии); зеркально для медвежьей — максимум недели.
- Покупка/продажа — **ниже/выше цены открытия дня** (00:00 NY), а не по рынку в любой момент: набор позиции идёт Пн–Ср, распределение — Чт–Пт.
- **Чт/Пт обычно формируют контрдвижение к недельному диапазону** — при бычьей неделе не рекомендуется набирать новый лонг в четверг/пятницу (можно пропустить движение, но это защищает от сделок против вероятного разворота).
- Если ключевая недельная цель достигнута рано (например, во вторник) — повышается вероятность консолидации или глубокой коррекции до конца недели.
- Сетапы значимо надёжнее внутри **killzones** (Asia/London/NY открытие) — вне их рынок, как правило, не даёт качественных моделей входа.

## Контекст и интерпретация

- Уровни DO/WO/MO/YO **не задают направление сами по себе** — служат точкой отсчёта.
- Правило: **выше открытия → лонговый настрой**, **ниже открытия → шортовый настрой**.
- Анализ сверху вниз: сначала определить bias на старшем периоде (год → месяц → неделя), затем применять паттерны на младших ТФ.
- Бычий HTF: аккумуляция под WO = фаза манипуляции → ожидать разворот вверх.
- Медвежий HTF: дистрибуция над WO = фаза манипуляции → ожидать разворот вниз.
