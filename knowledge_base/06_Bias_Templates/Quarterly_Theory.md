# Квартальная теория (Quarterly Theory)

Развитие концепции PO3: **«Теория цикла дня»**. Разделяет торговое время на кварталы (четверти), каждый из которых несёт определённую алгоритмическую роль. Устраняет двусмысленность за счёт конкретных временных ориентиров. Универсальна для всех таймфреймов и стилей торговли.

> Ключевой принцип: вся квартальная теория строится на **расскореляции между активами**. Торгуем продолжение ордер флоу, а не ищем глобальные разворотные точки.

---

## Фракталы времени

Время фрактально. Каждый цикл делится на **4 квартала**:

### Годовой цикл

| Квартал | Период |
|---|---|
| Q1 | Январь–Март |
| Q2 | Апрель–Июнь |
| Q3 | Июль–Сентябрь |
| Q4 | Октябрь–Декабрь |

### Месячный цикл (отсчёт с первой полной недели)

| Квартал | Период |
|---|---|
| Q1 | 1-я полная неделя месяца |
| Q2 | 2-я неделя |
| Q3 | 3-я неделя |
| Q4 | 4-я неделя |

> Если первая неделя месяца неполная — она пропускается (считается искажением).

### Недельный цикл

| Квартал | Период |
|---|---|
| Q1 | Понедельник |
| Q2 | Вторник |
| Q3 | Среда |
| Q4 | Четверг |

> Пятница не входит в недельный цикл — имеет специфическую функцию (см. [[../09_Setups/TGIF_Setup|TGIF Setup]]).

### Дневной цикл (= 4 торговые сессии по 6 ч)

| Квартал | Сессия |
|---|---|
| Q1 | Азиатская |
| Q2 | Лондонская |
| Q3 | Нью-Йоркская |
| Q4 | Дневная (afternoon) |

### 90-минутные циклы (NY Time, UTC−4)

**Азиатская сессия:**
- Q1: 18:00–19:30 · Q2: 19:30–21:00 · Q3: 21:00–22:30 · Q4: 22:30–00:00

**Лондонская сессия:**
- Q1: 00:00–01:30 · Q2: 01:30–03:00 · Q3: 03:00–04:30 · Q4: 04:30–06:00

**Нью-Йоркская сессия:**
- Q1: 06:00–07:30 · Q2: 07:30–09:00 · Q3: 09:00–10:30 · Q4: 10:30–12:00

**Дневная сессия (afternoon):**
- Q1: 12:00–13:30 · Q2: 13:30–15:00 · Q3: 15:00–16:30 · Q4: 16:30–18:00

## Функции кварталов

**Q1** — барометр для прогнозирования последующих кварталов:
- Q1 широкий → ожидаем консолидацию в Q2
- Q1 узкий → ожидаем расширение в Q2

---

## True Open (Истинное открытие)

**True Open** — начало **Q2** каждого цикла. Основной компонент квартальной теории: временной фильтр для определения Judas Swing и Stop-Hunts.

- **Бычий контекст**: покупаем **ниже** True Open цикла
- **Медвежий контекст**: продаём **выше** True Open цикла

### True Opens по уровням (NY Time, UTC−4)

| Цикл | True Open |
|---|---|
| Год | Первый понедельник апреля |
| Месяц | Второй понедельник месяца |
| Неделя | Понедельник 18:00 |
| День | 00:00 (полночь) |
| Азиатская сессия | 19:30 |
| Лондонская сессия | 01:30 |
| Нью-Йоркская сессия | 07:30 |
| Дневная сессия | 13:30 |

**Stacked True Opens** — Premium/Discount True Opens: помогают определить, в зоне премиума или дисконта относительно времени находится цена.

> Never buy above True Open. Never sell below True Open. Если видим Bullish SMT над True Open (или Bearish под) — игнорируем его.

## AMDX & XAMD — два шаблона алгоритма

### AMDX

| Квартал | Фаза | Описание |
|---|---|---|
| Q1 | **(A)ccumulation** | Консолидация, узкий диапазон |
| Q2 | **(M)anipulation** | Judas Swing (торгуем) |
| Q3 | **(D)istribution** | LRLR — направленная экспансия (торгуем) |
| Q4 | **(X)** | Продолжение или разворот предыдущего Q |

### XAMD

| Квартал | Фаза | Описание |
|---|---|---|
| Q1 | **(X)** | Продолжение или разворот предыдущего Q |
| Q2 | **(A)ccumulation** | Консолидация в широком диапазоне |
| Q3 | **(M)anipulation** | Judas Swing (торгуем) |
| Q4 | **(D)istribution** | LRLR — направленная экспансия (торгуем) |

> При XAMD True Open Q2 всегда является истинным открытием, даже если накопление происходит именно в Q2. Judas Swing формируется в Q3 относительно этого открытия.

### HTF PDA по таймфреймам входа

| Вход | Нужен HTF PDA |
|---|---|
| 1M | 15M PDA |
| 5M | 1H PDA |
| 15M | 4H PDA |
| 1H | 1D PDA |
| 4H | 1W PDA |

## SSMT (Sequential Smart Money Technique)

**SSMT** — SMT, образующееся между **последовательными кварталами** + между двумя/тремя близко коррелирующими активами.

Экстремумы для SSMT не обязаны формироваться в одно время — главное, чтобы это были экстремумы своего квартала.

### Трида для поиска SSMT

- **Forex**: EUR / GBP / DXY
- **Индексы**: 30 (YM) / 100 (NQ) / 500 (ES)
- **Бонды**: 5-летние / 10-летние / 30-летние
- **Крипто**: BTC / ETH / топ-актив по рынку

### Сравнения в цикле

**Дневной/месячный цикл:**  
Q1–Q2 · Q2–Q3 · Q3–Q4 · Q4–Q1

**Недельный цикл:**  
Q1–Q2 · Q2–Q3 · Q3–Q4 · Q4–Пятница (TGIF) · Пятница–Q1

### Минимальные ТФ закрытия свечей для SSMT

| Цикл | Минимальный ТФ |
|---|---|
| Micro Session | 1M |
| Session | 5M |
| Daily | 15M |
| Weekly | 1H |
| Monthly | 4H |

> SSMT только тенями — менее вероятное или коррекционное. Для подтверждения ждать закрытия свечи.

### Hidden SSMT (HSSMT)

Фокус на телах (не тенях). Когда тела свечей показывают расхождение (особенно на 4H, Monthly Cycle) — сигнал готовности цены к развороту.

### Инвалидация SSMT

- SSMT старшего цикла отменяет младший.
- HTF цикл формирует LTF SSMT — это валидно.
- Не искать глобальных разворотов в 90-минутном / дневном цикле — речь об интрадей сделках.

### Наблюдения по SSMT

- Два SSMT подряд в последовательных парах (Q1–Q2 и Q2–Q3) — маловероятно; Q1–Q2 и Q3–Q4 — высокая вероятность.
- Если бычий и медвежий SSMT в одном цикле — первый SSMT выступает магнитом для цены.
- Актив, **не снявший** ликвидность при SMT, имеет бо́льшее движение в дальнейшем.
- Единственный вариант разворота Q4 — наличие SSMT; без него разворот маловероятен.

### Silver Bullet

Ключевые промежутки, в которые формируется SSMT между Q3 и Q4: **10:00–10:30 и 10:30–11:00** (NY Time).

## Time Theory (правила по времени)

1. Не торговать в **банковские праздники** и следующий день после них.
2. Не входить **до объявления** CPI / NFP / FOMC / ставок. В неделю NFP торговля возможна до среды NY AM включительно.
3. Торговать **через 15–30 минут после новостей** (лучшая точка входа — именно в этот период).
4. **Январь** — наименее вероятный месяц для торговли.
5. Если новости в 08:30 → трейд формируется в **Q3 NY AM (09:00–10:30)** по НЮ.

### Замечания по времени

- CPI у H/L дня — скрытая ликвидность. Если цена близко к хаю/лою, сформированному во время CPI — там много ликвидности.
- CPI обычно задаёт тренд всей недели.
- Новостные события обычно идут в направлении Weekly SSMT.
- Если цена снимает пул, формирует HTF+LTF SSMT за 30 мин до новостей → манипуляция уже состоялась → ожидать экспансию.

---

## Общие наблюдения

- Цена над TMO и TWO (True Monthly/Weekly Open) — медвежий индикатор.
- Q3 с бо́льшим диапазоном, чем Q1 и Q2 → Q4 ожидается ещё шире.
- Лучшее PA — 2-я и 3-я неделя месяца, иногда 4-я. Первая неделя — ничего ожидать не стоит.

---

## Модели (Setup Structure)

**Базовый паттерн SSMT**: HTF Cycle SSMT + No MTF SSMT + LTF Cycle SSMT → Entry

> Пример: Weekly SSMT → No Daily SSMT → 90-min SSMT → вход  
> Каждый сетап работает **только при наличии FVG** и входа от него.
