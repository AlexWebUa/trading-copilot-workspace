# Standard Deviation Projection (STDV)

**STDV (Standard Deviation Projection)** — инструмент проецирования ценовых диапазонов для определения вероятных целей движения. Базовый диапазон откладывается кратно вперёд, обозначая зоны замедления/разворота.

> STDV — вспомогательный инструмент. Применяется только в связке с контекстом, ликвидностью и структурой, не изолированно.

## Концепция

В ICT стандартное отклонение трактуется не как статистический разброс (Bollinger Bands), а как **кратные проекции базового ценового диапазона** вперёд от импульса. Аналогия: берётся отрезок AB (импульс), затем многократно откладывается за точку B.

## Построение через Fibonacci

Для построения используется **модифицированная сетка Fibonacci** с пользовательскими уровнями:

| Уровень Fibo | Значение |
|---|---|
| 1.0 | Начало импульса (точка A) |
| 0.0 | Конец импульса (точка B) |
| –1 | 1× AB за пределами B → **STDV –1** |
| –2 | 2× AB → **STDV –2** |
| –2.5 | 2.5× AB → **STDV –2.5** |
| –4 | 4× AB → **STDV –4** |

Для нисходящего движения: 1.0 = вершина, 0.0 = минимум. Для восходящего — наоборот.

Опционально: уровень 0.5 (Equilibrium / C.E.) — часто точка отката перед продолжением.

## Интерпретация зон

| Уровень | Поведение |
|---|---|
| **STDV –1** | Первое препятствие. Возможен небольшой откат или консолидация. В сильном тренде проходится легко. |
| **STDV –2 / –2.5** | **Критическая зона.** Признак перегретости: фиксация прибыли крупными игроками, возможен глубокий откат или разворот. Совпадение с уровнями ликвидности/FVG усиливает значимость. |
| **STDV –4** | **Предельное расширение.** Редко; обычно — при значимых новостях. Финальный таргет для позиционных трейдеров. Почти гарантированно вызывает разворот или длительную консолидацию. |
| **Выше –4** | Экстраординарный сценарий (панические движения, интервенции). Шаблоны STDV временно теряют актуальность. |

## Применение

- Планирование зон TP и переноса SL при достижении ключевых уровней
- Фильтрация входа: если цена уже у STDV –2/-2.5, оценивать риск продолжения осторожнее
- Совмещение с пулами ликвидности, OB/FVG, Value Area — зоны пересечения = высоковероятные точки реакции
