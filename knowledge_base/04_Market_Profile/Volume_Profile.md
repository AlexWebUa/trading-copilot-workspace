# Volume Profile

**Volume Profile (VP)** — инструмент, отображающий распределение **объёма** по ценовым уровням за выбранный период. В отличие от TPO-профиля, который считает **время** нахождения цены на уровне, VP считает реальный торговый **объём**. Результат — горизонтальная гистограмма: длина столбца на каждом уровне пропорциональна количеству контрактов/акций, проторгованных на этой цене.

> Если TPO-профиль отвечает на вопрос «сколько времени рынок провёл на этом уровне», то Volume Profile отвечает «сколько денег сменило руки на этом уровне». Для анализа крупного капитала второй вопрос важнее.

## Типы Volume Profile

| Тип | Период | Применение |
|---|---|---|
| **Session VP (SVP)** | Одна торговая сессия (RTH) | Основной — оценка структуры текущего дня, VAH/VAL, POC |
| **Fixed Range VP (FRVP)** | Произвольный диапазон (ручной) | Анализ конкретного swing, диапазона консолидации, HTF-зоны |
| **Visible Range VP (VRVP)** | Видимый участок графика | Быстрая оценка текущего «среза» рынка; чувствителен к зуму |
| **Composite VP** | Несколько сессий / недели / месяц | Среднесрочный анализ; применяется как [[../04_Market_Profile/Composite_Market_Profile|Composite Profile]] |

## Ключевые элементы

### POC (Point of Control)
Ценовой уровень с **наибольшим объёмом** за период — аналог TPO POC, но точнее: крупный капитал концентрировал сделки здесь. VP POC чаще является сильным магнитом, чем TPO POC, поскольку отражает реальный денежный поток, а не просто присутствие цены.

→ Подробнее: [[../04_Market_Profile/POC|Point of Control]]

### Value Area (VAH / VAL)
≈70% всего объёма сессии. Используется идентично TPO Value Area. Разница: в VP границы более «острые» — объёмный консенсус определён точнее.

→ Подробнее: [[../04_Market_Profile/Value_Area|Value Area]]

### HVN — High Volume Node
**Уровень/зона с аномально высоким объёмом** относительно соседних. Признак **принятия** цены участниками рынка (acceptance). Цена имеет тенденцию **замедляться и ротировать** вблизи HVN — здесь находятся «тяжёлые» позиции, которые удерживают рынок.

Практические правила:
- HVN действует как зона поддержки/сопротивления с «мягкими» краями.
- При движении в сторону HVN ожидать замедление → возможную консолидацию.
- Пробой HVN с объёмом = крупный игрок «расчищает» зону → продолжение.
- HVN предыдущей сессии / недели = сильный уровень для работы по retrace-сетапам.

### LVN — Low Volume Node
**Уровень/зона с аномально низким объёмом** — признак **отторжения** (rejection). Рынок прошёл эту цену быстро, не оставив сделок. Аналог [[../04_Market_Profile/Single_Prints|Single Prints]] в TPO-профиле.

Практические правила:
- Цена движется через LVN **быстро и без сопротивления** — «дыра» в профиле.
- LVN = потенциальный ускоритель: вход в LVN с правильной стороны → цель на следующем HVN или VAH/VAL.
- LVN на пути к таргету снижает риск — нет объёма, который «остановит» движение.
- LVN на пути стопа повышает риск — цена может проскочить уровень без реакции.

## VP vs TPO: практическое различие

| Параметр | TPO-профиль | Volume Profile |
|---|---|---|
| Что измеряет | Время на уровне (30-мин блоки) | Объём на уровне (контракты/акции) |
| POC | Уровень с макс. TPO-блоков | Уровень с макс. объёма |
| Сигнал HVN/LVN | Single Prints / Fat body | Явная асимметрия гистограммы |
| Точность | Зависит от таймфрейма | Зависит от качества данных (L2 vs синтетика) |
| Применение | Сессионный контекст, аукционный анализ | Подтверждение уровней, фильтрация ложных пробоев |

> В идеале TPO и VP используются **совместно**: TPO даёт структуру и тип дня, VP уточняет «весовые» зоны. Совпадение POC по обоим методам — сильный уровень.

## Интеграция с SMC-концепциями

### VP + Order Block
OB, расположенный в зоне HVN предыдущей сессии/недели — зона с двойным основанием: структурная + объёмная. Более надёжный POI для позиции.

OB, расположенный в зоне LVN — осторожно: цена может пройти сквозь него без реакции (нет «якорного» объёма).

### VP + FVG
FVG, образовавшийся внутри LVN — усиливает характер «пустоты». При ребалансировке цена пройдёт его быстро. FVG внутри HVN — ожидать медленное частичное заполнение.

### VP + Value Area
Работа от VAH/VAL в комбинации с объёмными данными:
- Цена тестирует VAH + объём падает + delta негативная → [[../04_Market_Profile/Initiative_vs_Responsive|Responsive Selling]] подтверждён.
- Цена пробивает VAL + растёт объём + в LVN снизу → VA Breakout с ускорением.

### VP + POC как таргет / стоп
POC предыдущего дня / недели — классическая цель при работе из POI:
- При шорте от VAH → первая цель: POC текущего дня.
- При лонге от VAL → первая цель: POC текущего дня.

## Сигналы перераспределения

| Паттерн | Описание | Интерпретация |
|---|---|---|
| **Volume Gap** | LVN между двумя HVN | Цена «провалится» через зазор; LVN = ускоритель |
| **Double Distribution** | Два отдельных пика объёма в одном профиле | Рынок проходил два отдельных баланса; граница между ними — ключевой level |
| **P-Shape Profile** | Высокий объём сверху, тонкий хвост снизу | Накопление вверху; шорт-позиции ловушка (признак бычьего перераспределения) |
| **b-Shape Profile** | Высокий объём снизу, тонкий хвост сверху | Распределение вверху; лонг-позиции ловушка (признак медвежьего распределения) |
| **D-Shape (Normal)** | Симметричный профиль с POC по центру | Сбалансированный день; ожидать ротацию внутри VA |
