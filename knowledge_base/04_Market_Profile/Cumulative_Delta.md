# Cumulative Delta (CD)

**Cumulative Delta (CD)** — нарастающая сумма дельты за выбранный период. **Delta** одной свечи = Ask Volume (агрессивные покупки) − Bid Volume (агрессивные продажи). CD суммирует эти значения последовательно, формируя индикатор в виде линии или гистограммы под ценовым графиком.

$$\text{CD}_n = \sum_{i=1}^{n}(\text{Ask}_i - \text{Bid}_i)$$

> Delta не показывает направление рынка — она показывает **кто** двигал цену. Растущая цена с позитивной delta = покупатели агрессивны. Растущая цена с негативной delta = цену тянут лимитные ордера продавца, не маркет-байеры — потенциально слабое движение.

## Delta одной свечи vs Cumulative Delta

| Инструмент | Что показывает | Применение |
|---|---|---|
| **Delta свечи** | Баланс агрессии внутри одной свечи | Подтверждение разворота / продолжения на локальном уровне |
| **Cumulative Delta** | Накопленный дисбаланс за сессию / период | Оценка доминирующего давления, дивергенции с ценой |
| **Delta POC** | Уровень с максимальной накопленной дельтой | Зона наибольшей концентрации агрессивных сделок |

## Базовые сценарии: совпадение Price + Delta

### Здоровый тренд вверх
Цена обновляет хаи → CD растёт → подтверждение: агрессивные покупатели движут рынком. Продолжение тренда вероятно.

### Здоровый тренд вниз
Цена обновляет лои → CD падает → подтверждение: агрессивные продавцы движут рынком. Продолжение тренда вероятно.

## Дивергенции: сигналы слабости

Дивергенция CD ≠ сигнал входа сам по себе. Это **предупреждение о слабости** текущего движения, которое требует подтверждения структурой и контекстом.

### Bearish Divergence (скрытая продажа)
Цена обновляет High → CD не обновляет High (или падает). Интерпретация: новый хай формируется без реального покупательского давления. Лимитные продавцы поглощают маркет-байеров. Сигнал потенциального разворота вниз.

**Контекст применения**: цена у HTF POI (OB, VAH, FVG) + Bearish Delta Divergence → усиливает шорт-сетап.

### Bullish Divergence (скрытая покупка)
Цена обновляет Low → CD не обновляет Low (или растёт). Интерпретация: новый лой формируется без реального давления продавцов. Лимитные покупатели поглощают маркет-селлеров. Сигнал потенциального разворота вверх.

**Контекст применения**: цена у HTF POI (OB, VAL, FVG) + Bullish Delta Divergence → усиливает лонг-сетап.

## Delta в ключевых структурных точках

### CD при снятии ликвидности (Sweep)
Ликвидность снята → проверить CD в момент снятия:
- **Снятие BSL + CD не растёт / падает** → покупателей нет на новом хае → манипуляция подтверждена → шорт.
- **Снятие SSL + CD не падает / растёт** → продавцов нет на новом лое → манипуляция подтверждена → лонг.

Это один из сильнейших сигналов: ценовое движение (sweep) не поддержано реальным агрессивным потоком — значит, оно создано для сбора стопов, а не для тренда.

### CD при тесте POI
При возврате цены к [[../07_POI/POI|POI]]:
- **Бычий POI (OB, VAL, FVG)**: цена касается зоны → CD разворачивается вверх (дельта становится позитивной) → лимитные покупатели активны → подтверждение лонга.
- **Медвежий POI (OB, VAH, FVG)**: цена касается зоны → CD разворачивается вниз → лимитные продавцы активны → подтверждение шорта.

### CD при пробое структуры (MSS / BOS)
[[../02_Market_Structure/Market_Structure_Shift|MSS]] с сильным CD в сторону пробоя = истинный слом структуры. MSS без поддержки CD (нейтральный или противоположный) = риск ложного пробоя (Bull/Bear Trap).

## Delta Divergence vs Price Action: таблица сценариев

| Цена | CD | Интерпретация | Действие |
|---|---|---|---|
| Растёт | Растёт | Здоровый восходящий тренд | Работать по тренду, лонги |
| Растёт | Падает / нейтральна | Bearish Divergence: скрытые продажи | Готовиться к развороту (у POI) |
| Падает | Падает | Здоровый нисходящий тренд | Работать по тренду, шорты |
| Падает | Растёт / нейтральна | Bullish Divergence: скрытые покупки | Готовиться к развороту (у POI) |
| В диапазоне | Острый пик вниз + возврат | Absorption продавцов, покупатель удержал | Потенциальный лонг от уровня |
| В диапазоне | Острый пик вверх + возврат | Absorption покупателей, продавец удержал | Потенциальный шорт от уровня |

## CD и VWAP

CD хорошо работает в паре с [[../04_Market_Profile/VWAP|VWAP]]:
- Цена выше VWAP + CD растёт → бычий режим подтверждён.
- Цена выше VWAP + CD падает → скрытая слабость выше справедливой стоимости → риск возврата к VWAP.
- Цена пробивает VWAP вниз + CD резко падает → инициативная продажа, не responsive → вероятно продолжение.

## Периоды привязки CD

| Период | Применение |
|---|---|
| **Session CD** (сброс ежедневно) | Основной для интрадей: оценка дневного давления |
| **Fixed Range CD** | Конкретный swing или диапазон консолидации |
| **Perpetual / накопительный** | Долгосрочный анализ (свинг, крипта) |

> Сброс CD с началом каждой сессии (RTH open) — стандартная практика для фьючерсов. При переносе позиции через сессию учитывать, что «история» CD обнуляется.

## Ограничения

- **Не самостоятельный сигнал**: CD — вспомогательный инструмент. Дивергенция без контекста (нет HTF POI, нет структуры) = шум.
- **Качество данных**: как и Footprint, CD требует тиковых данных. TV-версии приблизительны.
- **Absorption vs Exhaustion**: сильный негативный пик CD на росте цены может быть и Absorption (покупатель поглощает продавцов) и Exhaustion (продавцы навалились). Различение — через объём и [[../04_Market_Profile/Footprint_Imbalances|Footprint]].
