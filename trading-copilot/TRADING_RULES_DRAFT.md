## 1. Базовая философия

- **«Цена движется от ликвидности к неэффективности»** — главный принцип
- Два базовых инструмента: **liquidity + imbalance**
- Работать на **факте, а не догадке** — никакого «хочу, чтобы это сняли»
- Идти за **актуальным трендом**, даже если он оставляет за собой компрессию
- Любая модель работает только при **правильно определённом контексте**
- **Приоритет: высокий WR > высокий RR.** Цель — стабильный ежемесячный доход, а не единичные крупные сделки

## 2. Стек таймфреймов и их роли

| ТФ | Роль |
|---|---|
| **W1 / D1** | Глобальный контекст, глобальные таргеты (взаимозаменяемы — тот, что даёт больше информации). Ключевые пулы ликвидности, ключевые имбалансы |
| **H4 / H1** | Основной рабочий ТФ. Триггеры (POI для входа) и таргеты. Ликвидность в рамках предыдущих сессий / дней |
| **M30 / M15** | Уточнение зон интереса внутри HTF POI; локальная структура. Могут использоваться и для входа |
| **M5 / M3 / M1** | Основной ТФ входа |

---

## 3. Синхронизация и рассинхронизация

**Приоритет ТФ:** HTF > LTF. При расхождении — контекст старшего ТФ является определяющим.

Синхронизация происходит между любыми таймфреймами. **Чем больше последовательных ТФ синхронизировано между собой — тем лучше условия для сделки.**

Пример уровней синхронизации:
- W1 ↔ D1 ↔ H4 ↔ H1 — максимальный синхрон, лучшие условия
- D1 ↔ H4 ↔ H1 — хороший синхрон
- H4 ↔ H1 — локальный синхрон, осторожно с таргетами

| Состояние | Определение | Следствия |
|---|---|---|
| **Синхрон** | Несколько последовательных ТФ движутся в одном направлении | Лучшие условия. Можно держать >1 рабочего дня. Можно входить против рейда ликвидности. Только тейк/стоп — за чартом не следим |
| **Рассинхрон** | Младший ТФ идёт против старшего (движение младшего = коррекция к глобальной доставке) | Таргет = **ближайший высоколиквидный пул**. Средний RR < 2. Ручное сопровождение. Закрыть до London Close |

## 4. Типы POI

### 4.1 Неэффективность (механизм rebalancing)

| Тип | Определение |
|---|---|
| **FVG (Imbalance)** | Трёхсвечная модель с зазором между фитилём свечи 1 и фитилём свечи 3. Размечается фибоначчи фитиль-в-фитиль. Перекрытие — полное (Full Fill) или 0.5 |
| **IFVG (Inversion FVG)** | FVG, который был пробит насквозь (инвертирован); теперь работает как сопротивление/поддержка |
| **BPR (Balanced Price Range)** | Пересечение двух противоположных FVG. Более точная зона реакции. Формируется на V-образных движениях / быстрых поглощениях |
| **GAP** | Дневной / недельный гэп открытия |

### 4.2 Блоки (механизм mitigation)

| Тип | Определение |
|---|---|
| **Sponsored Candle (SC)** | = OB, снявший ликвидность. Последняя медвежья свеча перед импульсом вверх (или наоборот), которая **также убрала пул ликвидности**. Используется **вместо** классического OB |
| **Breaker Block (BB)** | OB, полностью прошитый FVG-свечами. Торгуется в связке с FVG 50%. Встречается редко |
| **Rejection Block (RB)** | 2-свечная модель разворота: тело второй свечи полностью поглощает первую (смена контроля). Формируется у LP или внутри FVG |

> **Классический OB не используется** — только Sponsored Candle.
> **Mitigation Block не используется.**

### 4.3 Прочее

| Тип | Определение |
|---|---|
| **STB / BTS** | Sell-to-Buy / Buy-to-Sell зоны |
| **IMB как модель входа** | H4/H1 FVG используется как POI входа; внутри ищется манипуляция и модель на LTF |

## 5. Правила валидации POI

POI считается валидным только при выполнении условий:

1. **POI сняло ликвидность** (обязательно — если не сняло, оно само станет ликвидностью)
2. **За POI нет ликвидности** (никаких крупных пулов, которые могут протащить цену сквозь него)
3. **Желательно не тестировано** (каждый тест снижает вероятность удержания)
4. **Перед POI есть Inducement** (ликвидность-приманка, которая притянет цену к зоне)
5. **Находится в Premium/Discount зоне** (OTE диапазон — цена чаще делает RTO сюда)
6. **Синхронизация со структурой** (желательно; контртрендовые позиции — редкое меньшинство)

## 6. Модели входа

### 6.1 Три разворотных подтверждения (что искать на LTF после прихода в POI)

| Модель | Описание |
|---|---|
| **BOS / CHoCH / Shift** | Пробой фрактальной или структурной точки на M3–M15. Для ЛОНГ: BOS выше рейда. Для ШОРТ: BOS ниже рейда |
| **Инверсия** | Отмена предыдущего сценария через инверсию: Breaker Block, Inversion FVG, BPR. Включает QM (Quasimodo) и Failure Swing — обновление экстремума с разворотом без нового HH/LL |
| **Change in State of Delivery (Поглощение)** | Одно движение поглощает другое. Sponsored Candle / Propulsion Block. Работает лучше на M15 или в двойных формациях |

### 6.2 Четыре динамических модели входа (PashaTrltsk)

| Модель | Условия | Примечание |
|---|---|---|
| **Default** | Контекст + снятие ключевой ликвидности + BOS (M3–M15) | Самая частая |
| **Internal Manipulation** | Контекст + снятие ключевой ликвидности + внутренняя манипуляция на LTF | Главные контекстные таргеты должны оставаться не снятыми |
| **LTF OF** | Контекст + Order Flow на LTF | Главные контекстные таргеты должны оставаться не снятыми |
| **Return to IMB** | Возврат цены в имбаланс после пробоя | Подходит для любого релевантного IMB |

### 6.3 Сетап 1H3M (Bellissimo) — основной интрадей сетап

**Таймфреймы:** H1 (анализ) → 3M (вход)

**Чеклист (все пункты обязательны):**
1. ✅ Свип ликвидности в сторону контекста (фрактальная свеча **текущего дня**, максимум вчерашнего — старше не рассматривается)
2. ✅ 3M BOS на крайнем фрактале
3. ✅ Для ЛОНГ: 3M BOS выше рейда; для ШОРТ: 3M BOS ниже рейда
4. ✅ Ликвидность снята **без закрепа на H1** — только свип (закреп на H1 = инвалидация)
5. ✅ FTA (First Trouble Area) не слишком близко к точке входа
6. ✅ В рамках OTT

**Вход:** маркетом (возможно на тесте)
**RR:** 1.5–2.0 типично

### 6.4 Сетап 1HIMB (самостоятельный, повышенный риск)

**Условие:** H1 FVG сформирован **сегодня** (вчерашние не рассматриваются) → цена ныряет в него
**Модель входа:** свип на 3M внутри H1-имбаланса + 3M BOS
**Инвалидация:** закрытие H1-свечи над/под FVG (после инверсии)
**Вход:** на закрытии 3M-свечи

> Самостоятельный сетап, но более рисковый чем 1H3M. Требует повышенного внимания к контексту.

### 6.5 Логика Yura Pukaliak

- **Модель:** снятие ликвидности → поглощение движения, которое привело к снятию
- **Лестница ТФ:** H4 свип → вход на 15M; H1 свип → вход на 5M
- **FVG как POI:** цена приходит в FVG → наблюдаем как закрываются свечи от уровня 0.5 (валидация силы имбаланса)
- Не ждать доп. подтверждений — ловить движение в начале
- **OB не используется вообще**
- При встрече FTA в виде H1 IMB: можно выйти с позиции, если внутри формируется модель

## 7. Управление позицией

### 7.1 Стоп-лосс
- За фитиль свечи / SC / экстремум POI

### 7.2 Брейк-Ивен
- **Без BE по умолчанию** (вылет в BE морально хуже стопа; малая амплитуда сетапов)
- **Исключение:** BE при выходе новостей во время открытой позиции; после снятия больших пулов ликвидности

### 7.3 Частичный тейк / Таргеты
- **FTA (First Trouble Area):** если по пути к основному таргету встречается имбаланс или структурный уровень — цена может развернуться после его снятия. Стандартный сброс позиции: **80% на FTA, 20% на основной таргет**
- **Основной таргет:** ближайший высоколиквидный пул (BSL/SSL)
- **Таргет никогда не ставится на переснятие** уже снятой ликвидности
- **Синхрон:** можно тянуть до W1/D1 пулов ликвидности; держать >1 рабочего дня
- **Рассинхрон:** таргет = только ближайший пул; закрыть до London Close

### 7.4 Риск
- **Стандартный риск:** 1% на сделку
- **Рисковые сделки** (любая сделка с повышенной неопределённостью): 0.5% риска
- Минимальный RR: **1.5**

## 8. Сессии и тайминги

### 8.1 Торговые сессии

Все времена — **по Киеву (EET/EEST)**.

| Сессия | Время (Киев) |
|---|---|
| **Азиатская** | 02:00–10:00 |
| **Франкфуртская** | 09:00–10:00 |
| **Лондонская** | 10:00–18:00 |
| **Нью-Йоркская** | 15:00–22:00 |
| **NYSE Open** (акции) | 16:30 |

Все временны́е рамки используются для определения контекста, тайминга манипуляций и ожидания сетапов.

### 8.2 OTT (Optimal Trade Time)
- **09:00–17:00 по Киеву** — основное торговое окно
- После 17:00 Киев → скип (OTT завершён)

### 8.3 Ланч / Пре-NY
- Если аккаунт в плюсе → **не закрываем открытую позицию** в период Ланч/Пре-NY

### 8.4 NYM (New York Midnight — 00:00 EST)
- Ключевой уровень: аккумуляция под NYM, дистрибуция над NYM

### 8.5 Judas Swing (контекстный ориентир, не торговый сигнал)
- Азиатская сессия боковая → ложный свинг 00:00–05:00 NY, противоположный истинному направлению дня
- Формирует лой или хай дня (в зависимости от BIAS)
- **Цель:** понять где формируется дневной H/L, а не точка входа
