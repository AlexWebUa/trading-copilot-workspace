# 🔍 Code Audit - Краткая инструкция

## Как запустить аудит кодовой базы?

### Вариант 1: Полный аудит (рекомендуется)

```
Нажмите Ctrl+Shift+I (или используйте Command Palette)
Введите: /CodeAuditCoordinator
Нажмите Enter

Затем укажите:
- Путь: d:\Projects\vibecoding\trading-copilot-workspace
  (или оставьте пусто для текущего проекта)
- Тип анализа: full
```

### Вариант 2: Быстрый аудит

```
/CodeAuditCoordinator
Путь: [ваш путь]
Тип анализа: quick
```

### Вариант 3: Анализ конкретного модуля

```
/CodeAuditCoordinator
Путь: [ваш путь]
Тип анализа: focus:trading-analyzer
```

---

## ✅ Что произойдёт?

1. **🔎 Анализ** - CodeAnalyzer исследует кодовую базу (2-5 минут)
2. **📝 Логирование** - FindingsLogger сохраняет результаты (30 сек)
3. **📊 Отчёт** - Получаете итоговый отчёт с количеством находок

## 📊 Структура лога

Каждый лог содержит:

```
1. ❌ Ошибки в коде (Bugs)
   - Critical проблемы, требующие немедленного исправления
   - Примеры: undefined variables, missing error handling

2. 🔧 Нарушения Best Practices
   - Плохой стиль кода, архитектурные проблемы
   - Примеры: неиспользуемые импорты, дублирование кода

3. 🚀 Возможности Оптимизации
   - Медленные алгоритмы, отсутствие кэширования
   - Примеры: O(n²) циклы, N+1 запросы

4. 🏗️ Возможности Рефакторинга
   - Дублирование (DRY), большие функции, SOLID нарушения
   - Примеры: одинаковая логика в 3 файлах

5. ⚡ Проблемы Производительности
   - Утечки памяти, неэффективные операции
   - Примеры: потекшие слушатели, неиндексированные БД

📊 + Таблица со статистикой
🎯 + Рекомендуемый порядок внедрения
```

---

## 🎯 Приоритеты

| Уровень | Действие | Пример |
|---------|---------|--------|
| 🔴 **Critical** | Исправить немедленно | Утечка памяти |
| 🟠 **High** | Исправить быстро | Отсутствие error handling |
| 🟡 **Medium** | Запланировать | Оптимизация БД |
| 🟢 **Low** | Рассмотреть | Неиспользуемые импорты |

**Рекомендация**: Начните с Critical, затем High, затем остальное.

---

## 📝 Пример находки

```markdown
#### 1. Memory leak in event listener
- **Файл**: src/events/listener.py:67
- **Приоритет**: Critical
- **Описание**: Слушатели никогда не удаляются из памяти
- **Решение**: Реализовать метод unsubscribe()
- **Статус**: not-started
```

## 🔄 Процесс исправления

1. **Найти**: Откройте лог → найдите проблему
2. **Понять**: Прочитайте описание и решение
3. **Исправить**: Сделайте изменения в коде
4. **Обновить**: Измените статус на `in-progress` → `completed`
5. **Повторить**: Запустите аудит снова для новых проблем
